## 独立使用的配置边界

独立用户沿本文件的方法与检查，以自己的已确认任务、原话、真实材料及输出目录执行。使用者身份、业务主题、样本库、专名纠正表、品牌及字幕/字体/美颜/美体/速度/音量数值仅属于使用者自用配置；其他用户保持自己的原片/原工程值或本次明确选定值。没有个人历史样本时校准本轮原话，不虚构过去的修改和效果。不调用公司状态库、自动化或私有客户资料；各阶段凭证保存用户本地记录。

# 选题执行标准｜怎样才算做对

本文件只定义短视频选题阶段的结果怎样才算正确，不定义操作步骤或参数，包括研究、入库和候选生成方法。操作顺序、工具和字段写入方法只读当前Skill；来源路由、状态、返修和停止条件只读选题Agent（独立模式使用本次材料与本地记录）。

## 使用方法

- 每个大步骤操作前：先读本文件对应章节，再读当前Skill的本步流程。
- 操作后：再读本文件同一章节，以原始来源、选题库实际行、候选卡和交付消息检查。
- 结论只写`通过`、`失败`或`未验证`；打开过页面、写过文件、运行过工具或保存过链接均不等于通过。

## 1. 来源与原料标准

- 合法来源有四种：本人主动观点、指定对标题面调研、关键词平台检索、本人已发表或本次指定的公众号文章改编。账号与搜索作品在找题阶段只按标题、发布介绍、标签及必要外显字段提供调研启发，不要求下载、转写或读取完整口述内容。
- 本人观点有可回读原话；原话、AI解释与建议分开，不补造本人经历、案例或结果。
- 公众号文章有可回读全文、原链接／归档来源、作者关系、阅读覆盖与改编授权；短视频核心判断、证据及边界可对应原文，题面与结构适合短视频受众。未知内容、他人经历和原文未证明的结果没有被补成使用者事实；公众号发布事实不等于短视频选题已采用、稿件已确认或已发布。
- 外部题面有平台、作品身份/直达来源、实际标题/介绍/标签及范围、观察时点和适配用途。源文字不能被AI拟题替代；缺字段或截断明确，未知互动不填0。
- 作者完整观点、论证、案例和结构未被题面推断成已验证；题面调研不自动产生观点或结构资产。已选题自己的判断与证据在立意阶段形成，另行明确借具体外部观点/结构时才按实际授权核验原来源。

## 1A. 双平台搜索与研究运行标准

完整找题按种子词Skill（独立模式使用本次材料与本地记录）完成范围冻结、搜索、题面调研、库维护与本次需要的推荐，运行验收读专项质量标准（独立模式使用本次材料与本地记录）。指定词/建池/试词按本次范围停止；搜索不能因找到一题省略剩余名单，不以账号或历史卡冒充本轮查询。标题、介绍、标签是本环节足够的内容范围，缺少口述正文不构成找题失败。

## 1B. 关键词提取与平台适配标准

关键词提取Skill（独立模式使用本次材料与本地记录）归选题Agent，接收已有商业模式结论，输出有具体业务用途、来源和平台判断的词单。业务未定返回商业模式，不从热词反推业务；本人直接给词搜索时不强制重新提取。

- 每词能回到业务问题、服务范围和预期结果；源表达、AI转换及保留/合并/待验证理由可核对。
- 同时判断观众关心的问题、可理解收益、题面表达与平台供给；已有标题/介绍/标签及互动证据有平台和时点，只有推断时标建议/待验证。
- 业务相关、平台可检索、入池、推荐、本人采用和实际效果分别有依据；高互动不等于算法保证或成交，兼顾流量没有偏离业务。
- 交接字段与Skill唯一约定一致，已授权找题时下游实际接收冻结名单并开始；只提词时停止，未搜索不写平台通过。

## 2. 外部对标研究标准

- 本轮范围、指定账号、平台与具体作品身份真实可回查；入口故障按种子词Skill恢复，不把登录或控制问题当作品不存在。
- 题面研究只有标题、发布介绍、标签与必要外显字段，没有调用下载、媒体提取、ASR或正文获取。介绍不等于口述正文，标签不可见不按词义补造。
- 每个拟保留对象有实际题面、业务问题/观看兴趣判断、当前库中用途与缺口；AI应用建议和源文字分开，未编出作者完整观点、论证或结构。
- 对话结论按[来源Skill的对话呈现](../SKILL.md)直接可读；后台仍保留逐条题面分析。实际覆盖、研究、主库、候选与送达分别判定，简洁展示不替代内容验收。0推荐可有研究价值，不凑题或恢复深读。
- 同平台同作品可比观察才比较变化；累计值、区间差值和变化速度分别记录，单次观察不证明增长或因果，缺数据保持未知。
- 研究完成记录必须证明抖音、小红书客户端与窗口、网页标签已按来源Skill的归属范围分别清理；本轮新开标签逐个关闭且浏览器整体保持。运行前既有、用户正在使用或归属无法确认的资源有保留依据且未被误关。任一应关闭资源仍在运行、关闭整个浏览器、误关用户资源或缺少清理记录，均判定本轮完成失败；保存断点的阻塞运行也适用同一标准。
- 少量账号／作品未访问、非核心字段缺失、小红书入口缺口、历史基线或周回溯索引未补齐，不阻断当天完成；必须同时留下缺口、影响范围、当前结论边界和后续维护入口，且报告不得声称相应范围已全量覆盖。主样本、选题接力或完整报告仍缺时，研究质量可判未完成，但若当日已有自动或手动研究结果向使用者实际交付，不得以质量未完成为理由再次自动执行同一任务；同日自动触发须按日运行登记静默停止。使用者明确再次手动要求的本次任务另行执行。

## 2A. 题面适配与推荐复核

- 来源适配检查有题材/受众、作品身份、短视频类型、日期与可见互动依据。形式未知如实保留，不凭头像认真人，不用视频识别或全文读取补齐本次题面任务。排除类型和时间窗口仍按种子词Skill及来源证据判断。
- 外显互动参考同平台、发布时长、作者背景及可见供给，不设未经确认的点赞阈值；粉丝未知不写低粉，播放未知不算播放互动率，跨平台互动不相加。
- 推荐复核有目标用户问题、业务适配、观看兴趣/增量、重复检查、源文字与待展开项；标题介绍标签足以支持题面判断，不能证明作者观点、论证、案例或完整结构。
- 正式候选仍按第4/4A节；来源齐备和互动较高不自动推荐，本人认可题面不等于稿件已完成。自己的观点、真实证据与结构在选择后完善，未增加全文研究前置。

## 3. 选题库标准

- 种子词搜索的调研启发价值体现为对唯一选题库的真实补充与完善；条目有来源、复用用途、当前状态及使用缺口即可按本节判断收录，不以每条当轮可直接拍摄为完成条件。收录、正式候选、本人选择及可写稿分别有相应依据；当轮没有可推荐题仍可形成有价值的调研积累，推荐与生产是否完成另行判定。完整观点、本人案例与结构不提前成为收录或候选前置，第4/4A节现行门槛继续有效。
- 收录对象能追溯到使用者原话或具体对标视频，并至少具有一个明确可复用的用户问题、观点、论证方法、结构或案例机制。
- 当前价值、不能直接使用的原因、重新启用条件或适用的新选题均已写清。结果卡题面虽无正文，只要能回到具体作品、代表互动、目标用户问题和可复用话题，仍可作为`储备题`；孤立标题、热点词、泛泛道理或完全重复且无新增部件的内容不进入资产行。观点与结构资产必须另有实际正文证据。
- 有复用价值的原料真实写入唯一选题库；同源或同一核心问题更新原行，不制造近义重复。
- 每条至少保留来源、当前价值、不能直接使用的原因、状态与重新启用条件；对标条目保留核心问题、观点、反认知、所需使用者证据和原视频。
- `储备题／待补证据／待补角度／只借部件`均不等于正式候选；只有当轮通过选题生成门槛才可标`正式候选`。
- 使用者明确认可题面时，按核心用户问题查重并入库；按第4节先判断值得展开，不要求生产材料齐全。来源未读的候选明示正文未知、未继承观点，原作研究状态继续按实际证据；原作具体观点或结构在使用前补齐。
- 主库所有状态与本轮变更有完整内部记录；有价值条目具备题目、状态、保留理由、证据、具体缺口和再考虑条件。可见回复默认展示正式推荐及重要储备变化，不强制全库快照；本人明确要求全部清单时在同一对话展开，不编造历史缺失字段。
- 写下“已入库”不算通过；必须回读实际行、字段和来源链接。存在可进入准入的原料时，同轮已实际进入选题生成。

- 选题、观点、结构分别分类保存并保留完整来源关联；一条作品可只收一项或多项，无需当下可拍才准入。日常路线积累题面问题、角度与可复用表达；题面不能凭标题制造作者观点或结构，使用者本人材料保持独立来源。
- 入库记录有适用条件、学习层级与使用对象，外部观点未冒充本人立场；跨库组合的结论与证据一致。非AI作品的表达结构可以学习，但不自动获得当前选题准入。

## 3A. 收录与推荐分类标准

收录标准与第4/4A节推荐标准分别验收；正式推荐同样写入唯一选题库，未推荐内容须满足第3节可追溯与复用价值才能收录。以下只判状态，不新增评分或生产前置。

| 状态／处置 | 成立依据与必要边界 |
|---|---|
| 正式候选 | 当前第4/4A节及相关来源要求通过，值得本人选择；记录来源、用户问题、观看理由、去重与待展开项。完整本人观点、案例和结构未齐不一票否决 |
| 储备题 | 有可追溯问题与明确复用价值，但本轮暂缓或证据不足以正式推荐；说明保留原因、具体用途和重新考虑条件。仅题面不得继承未知观点 |
| 待补证据 | 缺会影响来源研究或推荐判断的具体证据，尚不能支持相应结论；写清缺项与补齐后复核范围。本人写稿材料待展开与原作证据缺失分别记录 |
| 待补角度 | 问题有价值，但当前讲法增量、具体程度或适配不足；写清需要形成的差异，未形成前不作为已通过正式候选 |
| 只借部件 | 整题不通过而某个观点、论证方法或结构有明确用途；题面部件有实际标题/介绍/标签依据；历史完整内容部件保留原授权、证据与适用条件，不因收录部件恢复整题资格 |
| 合并／不收录／不再使用 | 同源同核心问题且无独立新增价值合并旧行；无明确复用价值仅保留必要排除／去重信息；本人明确不希望再提按原话范围标不再使用 |

正式候选可以有“本人材料待立意／待补”的字段，不自动降成待补证据；借作者具体观点／结构前仍须有正文证据。只有采集成功、标题相似、互动高或本人未回复，均不能独立决定上述状态。

## 4. 正式候选标准

- 本节是完整选题标准，不以“三点概括”替换已确认要求。候选表示值得继续展开，不表示成稿材料齐全；明确取消本人完整观点、新成功案例、详细结构、证据论证/边界及整套改造方案作为题目前置审批。选择后再完成立意、结构与写稿验收。取消策略与统一依据（独立模式使用本次材料与本地记录）。

| 选题判断项 | 题面阶段要判断什么 |
|---|---|
| 人群与阶段正确 | 有专业积累、AI理解较浅的目标人群现在是否遇到这个问题，不预设已有大量客户/成熟产品 |
| 目标人群内部广泛 | 相关需求覆盖这群人中的多数或广泛适用，不把少数职业/成熟销售前提当大众入口；不用先做比例调查 |
| 痛点与观看兴趣强 | 用户为什么愿意点开，解决什么现实阻碍、弄清什么重要问题或获得什么机会/结果 |
| 有实质认知增量 | 有值得知道的新用途、能力、信息、判断或解法，不能只有常识口号/换词；优秀原作已具增量可继承 |
| 题面直接听懂 | 一句话知道谁做什么、为何值得看，不绕、不靠黑话或先懂技术概念 |
| AI主题与真实应用方向 | 围绕AI解决专业、内容、产品或经营中的真实问题，不能只贴AI标签、盘点工具或讲新闻参数 |
| 有可尝试方向且制作划算 | 能期待一个尝试方法或选择依据，复杂度适合本人表达；不要求题目前完成全套操作或成功验证 |
| 当前以流量型为准 | 主要观看动机是用户问题与收获，转化型/人设型暂不进入当前生产；不把推销换名放行 |
| 核心问题不重复 | 与已做题查语义重复，相同方法服务不同问题不自动合并，换标题不算新增 |

上述判断按实际题面、来源和本人反馈综合说明，不变成固定打分公式、每题全市场调查或写稿齐备检查。明确单题认可及条件按原话落实，未评价不猜通过。来源真实性、外部作品形式/日期/互动及题面读取范围按2/2A另行记录；这些不是要求本人稿件先完成。素材证据不足可以保留题面线索，借作者具体观点/结构前补正文。
- 原题是否适合与题面形式是否可迁移分别判断。使用者可认可“一分钟讲清几个易混淆事项”或“某件事就这样做”的题面形式，并在其他具体内容中复用；不能仅因原题非AI或使用本人不用的工具就丢弃已认可形式。该认可不等于原题、原工具或未知正文结构获准，OPC/豆包等中心题排除仍适用于实际拟讲内容；具体用户问题、实质AI用途和有价值内容形成后按本节复核。风险/成交题有具体AI参与方向可以再评，不以加AI字样代替真实应用。学术比较或作者单方面想讲、观众缺少关心理由的题面不通过。依据：10月10日本人逐条反馈（独立模式使用本次材料与本地记录）。
- 候选按本节与4A的现行要求判断，有本题受众、需求、增量和来源的实际依据。标注是建立、检验和校准标准的方法，不是生产核心模块；正常生产不以检索评分样本、填写样本ID或找到相近高分例为通过条件。标准边界不清、与使用者判断有分歧或明确开展校准时，才回查选题校准样本（独立模式使用本次材料与本地记录）。
- 实际使用标注证据时，来源批次与修订、原文、原分和备注可回读，正反例及适用差异如实说明；未命中不补造。0分不是正例，1分只及格，空分保持未知；题面分与开头分、AI归纳与本人备注分开。相似性不等于新题已获同分，历史高分不代替当前准入或批准生产；已纳入标准的明确反馈不能因不查样本而被忽略。
- 当前明确排除以OPC／一人公司为中心的选题，不能仅删字换壳；以豆包为中心的同类提报也按本人明确备注排除，不扩展成产品质量判断或内部工具禁用。企业级需求、企业AI采购/组织提效及面向企业客户提供AI服务的选题排除；老板管理和单纯把职场工作做好，也不能自动作为本频道受众入口。不能预设大多数目标观众已有很多客户、现成可出售Skill或公开方法的能力；只对这些少数前置条件成立的问题不满足广泛相关性。以“知识付费”为吸引点的陈旧题面同样不通过。上述边界来自样本原备注，仅约束当前短视频选题，不改写业务定位、产品或历史事实。
- 网站／App制作教程是当前低优先方向：使用者明确要求“怎么做网站和 app，这样的话题尽量不讲”。以如何建站、如何做App及零编程制作步骤为中心的候选默认不推荐；只有使用者另有明确选择或生产要求时再按本节其余门槛复核。该偏好不扩大成所有AI产品话题或方法类内容的禁令，也不据此否定工具能力、历史兴趣数据或本人内部开发实践。依据见本人反馈（独立模式使用本次材料与本地记录）。
- 当前不做纯概念科普或细步骤技术教学，包括“什么是AI工作流”和科研Skill设计长教程。简单解决一个观众关心的问题可以通过，例如把反复发生的工作做成可调用Skill；以具体收益和可讲清的过程区分，不因出现Skill、Agent或方法就误判为纯科普。评估制作性价比：理解与制作难度过高、当前用户收益低的题不优先。

- 题面第一次听就要知道具体问题和观看收益。“信任证据”“咨询承担什么作用”等黑话、纯学术/品牌概念不作为用户需求入口；不能把后台商业术语直接用作观众题面。已有客户、询价或成熟销售流程的前提要明写，面向少数人的销售优化降优先；本轮询价核验有真实痛点而被本人勉强通过，不能扩大成后端问题一律禁止。

- 受众相关、目标人群内部广泛、痛点/兴趣强继续作为选题判断条件。具体案例可以窄，实际需求须广泛；无需先量化覆盖百分比，也不能因此忽略仅少数人具备的客户/产品/技术前提。

- 常见题先看是否还有具体痛点和有用讲法，不仅因常见就淘汰。本人明确否定的“活人感很重要”、一人公司知识库科普等方向不自动恢复；本人对本轮知识库泛话题提出的显著观点/结构/画面差异条件仍保留。基础知识可以作必要铺垫，纯科普或复杂教学按本人偏好排除。

- 热点只作少数情况下的补充入口，不代替硬需求和认知增量；仍须与受众、AI应用和本稿证据相关。本要求不虚设未经确认的热点比例。

## 4A. 标注反推的选题要求

这是当前全样本分析（独立模式使用本次材料与本地记录）与第4节共同形成的执行要求；不是额外加权评分表。没有明确备注的打分原因属于AI解释，不能冒充本人定论。以下倾向用于比较与排序，不构成“同时出现这些词就通过”的公式。

| 要求 | 通过时能具体说清什么 | 不足或失败的表现 |
|---|---|---|
| 人群和阶段对 | 有专业积累、AI较初级的人现在会遇到什么；无需先拥有多数观众没有的客户、产品或技术条件 | 只因都属于AI/自媒体就判相似；把未开始的人直接带到成熟经营优化 |
| 需求有吸引力 | 为什么愿意看，解决什么阻碍或得到什么机会/可用结果；优先真实标注支持的个人尝试与内容实践需要 | 只解释行业/技术自身、泛泛正确判断，或只加“赚钱”“普通人”却没实质收获 |
| 具体但不窄 | 任务可认出、结果可想象；案例可以细，适用需要在目标人群内广泛 | 把局部功能一律判窄，或用大标题掩盖实际只服务少数职业/成熟阶段 |
| 有可尝试的路径 | 看完能知道尝试什么、怎样开始或按什么依据选择；成本/门槛可解释，不夸大容易程度 | 只列机会、环节、能力口号，或把低成本/三步当保证 |
| 有实质增量 | 新用途、新能力、新信息、新解法或值得知道的判断差异；仍核对行业是否已被讲烂 | 仅关键词新组合、句型反转、细节增多；“熟悉任务”不自动等于“陈旧答案” |
| 题面能听懂 | 一句话能明白谁要做什么、为何值得看；认可的好方向遇到绕口题面可重写 | 依赖后台解释才懂；只换词就把原0分题说成已获2分 |

- 0／1／2／3仍分别是不好／及格／好／特别好。AI预测单列，不能冒充本人分数；当前无3分选题锚点，不以虚构精确阈值宣布特别好。
- 高分旧题可以直接作为生产原料召回，保留原分和来源，经相应来源证据核验、当前准入与选择授权后推进；外部题面来源只核对标题、介绍、标签，借用具体作者观点或结构时另按实际授权补证；不得因它已用于学习而排除，也不得把它计为独立新题判断测试。
- 新题可与旧样本在需求与观看理由上相近，不要求全网首创；但“旧题换词／同一视频再改摘要”不能充当新样本。判断进步需未评分样本的事前判断与后续本人反馈，不能用已知2分稿获准拍摄代替。

- 人群名称对不等于需求阶段对。面向刚开始做自媒体的人，不能把AI认为重要的“评价内容好坏”直接当其硬需求；应对应本人明确指出的开始、选题、不会做、露脸障碍等真实场景。工具名、工具箱或流程名若让观众不知道与自己有什么关系、能得到什么，不因动作具体而判及格。
- 熟悉领域不自动判0：第四轮T04-01知识整理题2分，T04-07知识库便利性题1分，而T04-08绕口且被反复讲述的搭建题0分。分别核对实际任务、收益与题面，不能见“知识库”就一票否决，也不能因此放宽已明确排除的一人公司知识库题；无备注的2分原因仍未知。
- 2026-10-08校准进一步区分：重复工作沉淀成Skill、用AI验证生意/产品可通过；纯工作流科普、科研细节教程、已有客户才关心的销售判断、难懂品牌/咨询术语不通过。知识库和变现题按具体条件勉强保留。本人未评价的AI写文案题保持未知，未给数字评分不补分；已知样本落实不等于新题判断能力已验证提升。

## 4B. 标注学习更新的完成标准

本节只验收标注分析与标准校准任务，不是每条选题的必经生产步骤。标准已经明确时直接按标准生产，无需重复分析原样本。

- 校准选样跨模块不重复同一原视频或同一篇稿件，换标题、换摘要、截取不同段落不算新来源；新一轮默认不重复本人已经标注过的原作品。只换标注维度仍属重复，不能以节省观看时间为由复用。本人明确要求复测某条时才单列复测，不算独立新样本。此要求仅约束标注选样，不禁止正常生产研究同一优秀作品的多个部件。
- 样本能帮助区分好、一般、不好与仍有分歧的边界，不全选已认可的好视频；候选质量层次是AI事前判断，不能预设或补写本人分数。多样性还包括实际内容与表达方式，不能只换视频ID却仍提供高度同质内容；不为平衡数量造坏样本或凑固定比例。
- 评价项数量与独立来源数量分别统计；重复源的多维好评保留，但不能据此证明各维度标准已清晰或模型已学会。样本设计问题、材料缺陷、执行误判、标准含糊分别归因；同分而理由不同仍须记录。

- 原文、来源、样本ID、评分、原备注、批次修订与历史改分可回读；空分不是0，低分和已用于生产的样本不随候选清理。归档为只读证据，唯一改分入口不变。
- 每项归纳能追溯支持样本及实际存在的反例/边界，区分明确要求、跨样本倾向和未证实解释；没有备注不补造理由，没有反例记录检索范围，不凑引用。
- 完成一批学习不只指保存或分析：有与旧规则的对照、实际修订或有依据保留的结果、唯一主责文件及下次调用位置。冲突旧条款已替换，无双重标准；已知样本上的回放只证明没有明显矛盾，不冒充盲测提升。
- 已形成可用倾向时即可执行，不以没有万能公式、没有3分题或未再标200条为由停止；仍无法界定的分歧单列并据此补样本。纯确认保存的请求不越界改规则，批次完成/学习请求按已授权持续更新。

## 5. 状态、交接与停止标准
