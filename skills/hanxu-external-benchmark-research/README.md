# 韩叙 · 短视频选题调研助手

不知道下一条拍什么，想从指定账号和关键词中寻找选题启发。

## 适合谁

抖音、小红书创作者，以及需要持续研究受众兴趣的人。

## 你提供什么

研究平台、对标账号或关键词、时间范围、你的业务方向。

## 你会得到什么

来源明确的选题调研卡、候选建议、已覆盖范围和资料缺口。

## 下载与安装

[下载这个助手的安装包](../../packages/hanxu-external-benchmark-research.zip) · [返回七个助手的总介绍](../../README.md)

下载 ZIP 并解压，将整个 `hanxu-external-benchmark-research` 文件夹交给你电脑上的 Codex，说：“请帮我安装这个 Skill，检查所需依赖并告诉我如何调用。”也可以手动把完整文件夹放进 `~/.agents/skills/`。不要只复制 SKILL.md，配套文件也需要保留。如果安装后未出现，重启 Codex。

## 开始使用

安装后，在 Codex 中输入以下示例，并附上自己的材料：

```text
$hanxu-external-benchmark-research
根据我指定的账号和关键词，调研短视频题目并给出选题启发。
```

## 使用条件与范围

需要可用的平台访问或你提供的真实结果资料；格式检查脚本需要 Python 3。只读标题、介绍和标签时，不推断视频完整观点。

你需要提供自己的素材、授权和品牌信息。模型和工具的实际费用按你使用的服务计费。当前是可下载的 Skill 文件包；不是一个点开网页就能直接运行的在线应用。详细执行方法见 [SKILL.md](SKILL.md)。
