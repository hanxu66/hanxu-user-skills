# 韩叙 · 公众号写作助手

有观点和零散材料，想整理成一篇有逻辑的公众号文章。

## 适合谁

公众号作者、专业服务者、希望用文章讲清楚观点的人。

## 你提供什么

文章题目、核心观点、真实证据与案例、目标读者。

## 你会得到什么

证据整理、论证结构、公众号完整正文。

## 下载与安装

[下载这个助手的安装包](../../packages/hanxu-public-account-drafting.zip) · [返回七个助手的总介绍](../../README.md)

下载 ZIP 并解压，将整个 `hanxu-public-account-drafting` 文件夹交给你电脑上的 Codex，说：“请帮我安装这个 Skill，检查所需依赖并告诉我如何调用。”也可以手动把完整文件夹放进 `~/.agents/skills/`。不要只复制 SKILL.md，配套文件也需要保留。如果安装后未出现，重启 Codex。

## 开始使用

安装后，在 Codex 中输入以下示例，并附上自己的材料：

```text
$hanxu-public-account-drafting
根据我的观点和材料，整理证据与结构，写成一篇公众号文章。
```

## 使用条件与范围

需要可用的 Codex，以及你有权使用的材料。

你需要提供自己的素材、授权和品牌信息。模型和工具的实际费用按你使用的服务计费。当前是可下载的 Skill 文件包；不是一个点开网页就能直接运行的在线应用。详细执行方法见 [SKILL.md](SKILL.md)。
