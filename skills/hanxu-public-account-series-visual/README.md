# 韩叙 · 公众号封面制作助手

文章标题已定，需要统一风格的公众号封面或正文头图。

## 适合谁

公众号作者、栏目运营者，以及需要持续制作系列封面的人。

## 你提供什么

已确定标题、品牌或作者信息；可指定样式、期数和只做封面。

## 你会得到什么

公众号封面，或封面与正文头图组成的系列双图。

## 下载与安装

[下载这个助手的安装包](../../packages/hanxu-public-account-series-visual.zip) · [返回七个助手的总介绍](../../README.md)

下载 ZIP 并解压，将整个 `hanxu-public-account-series-visual` 文件夹交给你电脑上的 Codex，说：“请帮我安装这个 Skill，检查所需依赖并告诉我如何调用。”也可以手动把完整文件夹放进 `~/.agents/skills/`。不要只复制 SKILL.md，配套文件也需要保留。如果安装后未出现，重启 Codex。

## 开始使用

安装后，在 Codex 中输入以下示例，并附上自己的材料：

```text
$hanxu-public-account-series-visual
用我的文章标题和品牌信息制作公众号封面，并检查实际图片。
```

## 使用条件与范围

需要 Node.js、Python 3、Sharp 和中文字体；先在技能目录运行 npm install。

你需要提供自己的素材、授权和品牌信息。模型和工具的实际费用按你使用的服务计费。当前是可下载的 Skill 文件包；不是一个点开网页就能直接运行的在线应用。详细执行方法见 [SKILL.md](SKILL.md)。
