# 韩叙 · 小红书图文制作助手

逐页文案已经确定，需要制作封面和整套小红书图片。

## 适合谁

小红书创作者、知识博主、希望把内容做成图文卡片的人。

## 你提供什么

已确认的逐页文案、封面意图、品牌信息、获准使用的图片。

## 你会得到什么

1080×1440 图片、封面缩略图、整套预览和发布顺序。

## 下载与安装

[下载这个助手的安装包](../../packages/hanxu-xiaohongshu-visual.zip) · [返回七个助手的总介绍](../../README.md)

下载 ZIP 并解压，将整个 `hanxu-xiaohongshu-visual` 文件夹交给你电脑上的 Codex，说：“请帮我安装这个 Skill，检查所需依赖并告诉我如何调用。”也可以手动把完整文件夹放进 `~/.agents/skills/`。不要只复制 SKILL.md，配套文件也需要保留。如果安装后未出现，重启 Codex。

## 开始使用

安装后，在 Codex 中输入以下示例，并附上自己的材料：

```text
$hanxu-xiaohongshu-visual
按我提供的逐页文案和品牌信息，制作一套小红书图文图片。
```

## 使用条件与范围

文字图文需要 Node.js、Sharp 和中文字体；先在技能目录运行 npm install。模型图需实际可用的制作工具。

你需要提供自己的素材、授权和品牌信息。模型和工具的实际费用按你使用的服务计费。当前是可下载的 Skill 文件包；不是一个点开网页就能直接运行的在线应用。详细执行方法见 [SKILL.md](SKILL.md)。
