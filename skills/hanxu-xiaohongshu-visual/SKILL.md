# 韩叙 · 小红书图文制作助手

逐页文案已经确定，需要制作封面和整套小红书图片。

- **适合谁**：小红书创作者、知识博主、希望把内容做成图文卡片的人。
- **提供什么**：已确认的逐页文案、封面意图、品牌信息、获准使用的图片。
- **得到什么**：1080×1440 图片、封面缩略图、整套预览和发布顺序。
- **使用条件**：文字图文需要 Node.js、Sharp 和中文字体；先在技能目录运行 npm install。模型图需实际可用的制作工具。

先看[中文使用介绍](README.md)。执行时遵循下方原方法与配套标准。

## 使用者配置与独立使用

本文件同时保留使用者内部调用和独立用户模式，方法不分叉维护。使用者自用继续读取原对象、样本与状态工具；独立用户只使用自己提供的题目、观点、来源、正文、素材、授权、品牌及输出目录，不能读取使用者的私人库或替用户补造个人经历。下文使用者身份、业务方向、个人样本、品牌和参数是个人配置，独立使用不自动继承；使用者自己的原话、修改和已授权案例替代本人资料。原方法的事实、证据、适用边界与检查仍执行。

独立用户在自己的输出目录保存来源清单、版本、阶段结果和检查记录，可自行命名本地对象；不要求使用者内部对象ID、公司状态库或状态命令。材料已经齐全时按原顺序连续推进，确实缺失才补最小输入。内部Agent/上游/下游指本方法的阶段职责，独立任务按本次已授权范围执行，不需安装整套经营系统，也不自动建立定时任务或发布。安装包由本文件及其现有依赖生成；修改回原文件，导出目录不是另一份维护主档。

独立起点是使用者已确认逐页方案、图文正文、封面承诺及兑现页、内容类型、素材权限和输出位置；这不是找题入口。开工检查在用户目录记录来源/授权/红线/封面/当前版本，不依赖公司preflight数据库。调用随包原渲染脚本；姓名和照片自带。XHS-M仍按模型制作方法使用当前明确可用的渲染器，不用纯文字渲染冒充模型图。

## 原方法与执行流程

## 触发与输入

当前逐页方案完成且使用者本次命令允许制图时进入。先读总入口（独立模式使用本次材料与本地记录）、[封面与素材选择](references/封面与素材选择.md)，再按类型读取[文字图文制作](references/文字图文制作.md)或[模型图制作](references/模型图制作.md)。

最低输入：当前逐页方案、小红书发布正文及`body_char_count`、`body_limit_check`、`body_paragraph_check`、封面承诺及其正文兑现页、当前版本、内容类型、视觉意图、素材权限、批准样本或明确视觉基线、输出目录。本Agent传递正文但不改写正文。

## 唯一执行链

1. 先执行[封面与素材选择](references/封面与素材选择.md)，交出唯一封面意图、正式封面、270×360缩略图回读和可追溯素材清单；没有通过该Skill的硬门不得续行。
2. 运行`tools/content_production_preflight.py`，快照本次实际读取的入口、Agent、Skill、来源、权限、红线、选定封面和验收对象；PASS前不得正式生产。
3. 将选定封面作为第1页，再按内容类型调用对应制作Skill完成其余页面；制作Skill不得重新选封面类型、改封面承诺或换用未登记素材。
4. 生成发布顺序文件、封面缩略图和全套联系表。
5. 用实际渲染结果逐项检查尺寸、缺图、溢出、错字、层级、封面缩略图、人物遮挡、来源忠实和整套节奏；失败当轮修复并重新检查。
6. 提交`全套图文完成`，不负责改写命题或猜发布时间。

## 交接

- 交发布Agent（独立模式使用本次材料与本地记录）：当前版本图片目录、逐页方案、小红书发布正文及`body_char_count`、`body_limit_check`、`body_paragraph_check`、选定封面引用、缩略图回读、联系表、来源对照、视觉检查记录和`asset_manifest_ref`。
- 缺任一页面、选定封面与发布顺序第1页不一致、缩略图硬门未通过、未检查完整联系表或图片与当前逐页文案不一致，不可交接。
- 同一对象只交唯一当前版本；旧图片与旧检查自动失效。

## 返回、停止与清理

- 文案／关系错误退回图文策划Agent；纯视觉缺陷留在本Agent修复；来源或权限问题退回内容准入Agent。
- 工具不可用时保存当前方案和错误证据，停止在开工门或制作阶段，不用低保真占位冒充成品。
- 使用者否定视觉且不继续改，保留反馈和最终对比证据，清理未采用渲染与临时文件。


## 随包原渲染器

文字图文使用`scripts/render_xhs_full_article.mjs`，配置含objectDir、sourcePath、revision、sourceTitle、opening、ending、coverLines、eyebrow、subline、photoPath、authorLabel、brandLabel及输出规划。用户自带文章与有权使用的图片，保持段落完整。先在本目录运行`npm install`安装Sharp，再用`node scripts/render_xhs_full_article.mjs <用户配置.json>`。模型图沿模型图制作方法与当前实际可用工具执行，不声称纯文字脚本会生成任意模型图。
