# 韩叙 · 公众号标题助手

文章已经写好，想得到清楚、吸引人且符合正文的标题。

## 适合谁

公众号作者、编辑，以及需要比较标题方案的人。

## 你提供什么

最新完整文章、目标读者、你偏好的表达方式。

## 你会得到什么

多个标题方案、逐项比较、推荐标题及正文兑现检查。

## 下载与安装

[下载这个助手的安装包](../../packages/hanxu-public-account-title.zip) · [返回七个助手的总介绍](../../README.md)

下载 ZIP 并解压，将整个 `hanxu-public-account-title` 文件夹交给你电脑上的 Codex，说：“请帮我安装这个 Skill，检查所需依赖并告诉我如何调用。”也可以手动把完整文件夹放进 `~/.agents/skills/`。不要只复制 SKILL.md，配套文件也需要保留。如果安装后未出现，重启 Codex。

## 开始使用

安装后，在 Codex 中输入以下示例，并附上自己的材料：

```text
$hanxu-public-account-title
根据这篇完整文章生成标题方案，比较优缺点并推荐一个标题。
```

## 使用条件与范围

需要可用的 Codex 和最新完整正文；不会承诺未经验证的点击率。

你需要提供自己的素材、授权和品牌信息。模型和工具的实际费用按你使用的服务计费。当前是可下载的 Skill 文件包；不是一个点开网页就能直接运行的在线应用。详细执行方法见 [SKILL.md](SKILL.md)。
