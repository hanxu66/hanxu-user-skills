# 产品介绍视频｜官方介绍与模型动画

本文件维护产品、课程或企业官方介绍类视频的表达操作；是否调用由剪辑Agent绑定本人本次要求。它不是所有短视频的默认开头或默认画风，也不新增Agent或工作流。动画制作、声音、工程与导出继续调用[动画视频制作](动画视频制作.md)或[口播剪辑](../SKILL.md)，结果读[剪辑执行标准](剪辑执行标准.md)。

## 2026-10-17形式纠正：动画为主

本人对8980产品介绍V5明确指出：“这个视频应该是动画，定义是动画的形式为主，而不是PPT的形式为主”“总之其实都是形式上、视觉上的问题，节奏上的问题，就没有内容上的”。V6至V8制作时曾据此自行绑定故事型；这项解释已被下方V9本人明确指定PPT型覆盖。原话中的“像PPT播放”批评的是成片表达，不等于否定剪辑Agent命名的PPT型解释动画。保留此段形成过程，不再据此排除PPT型。

- 锁定已确认内容，先修形式、视觉与节奏，不因画面薄弱反复改写课程卖点、承诺或旁白。本人要求的全部有效问题仍保留。
- 主要解释段必须呈现对象的开始状态、具体动作和结果：例如材料整理成方案、同一任务经过方法调用产出初稿、检查后修正。用可见操作解释关系；固定标题、照片和列表逐页轮换，或给矩形框加淡入、连线亮点，仍属于课件式呈现，不能登记为本次动画形式已落实。
- 真实课堂、原图证言与正式履历融入动画节奏；为识别人群、精确模型或阅读证言，可短暂停留稳定画面。稳定信息段不能反过来支配全片。
- 配色按本对象实际画面检查，继承官网主色不等于把全片铺成深蓝底。背景、主文字、辅助文字、图形强调和照片共同核对，先看小样及手机尺寸的对比、协调与可读性；不将色值来自官网或技术导出成功当成视觉合格。
- 用实际运动片段复查动作是否解释内容，并在横竖两版检查主要对象、字幕与安全区。静态关键帧检查与连续播放分别留证；声音听辨、本人审美采用继续独立记录。

### 同日V7补充：颜色继承、图片与整屏证据

本人继续要求本对象颜色回到剪辑Agent已有的PPT型风格，同时明确“注意不能只是PPT，里面一定要配入大量的图片”。本次只继承[动画视频制作Skill的已确认视觉参数](动画视频制作.md)中的深灰底、米白字、橙色强调与字体；动画为主的形式要求持续有效，不能把颜色选择误作恢复PPT逐页形式的授权。

- 开头先呈现专业、清楚的整体模型，随后马上切入真实线下交付照片。模型先建立课程整体，真实现场随即承接；不以长时间静态模型占满开场。
- 按具体讲解交错使用已授权的真实讲解、课堂、练习和讨论图片。照片参与构图与镜头变化，主要关系仍由材料、任务、调用、产出和检查的动作承担；不退回统一“左照片、右列表”的重复模板，也不以图片数量替代质量判断。
- 本人要求完整模型或聊天记录时，所选课件保留整图，聊天保留该手机截图从顶部到底部的界面及上下文，不仅截一句评价。可从一张多屏拼图中分离完整单屏，不生成聊天界面、不增补聊天内容；匿名状态和来源取舍仍按真实素材检查。完整展示不等于所有文字可在数秒内读完，需分别检查横竖版比例、停留与主要信息。
- 本对象片尾不出现二维码或价格，不朗读价格；只使用本人指定的“对这个课程感兴趣的话可以联系我们”。这是本次介绍视频的表达取舍，不修改课程实际价格或权益，也不自动成为所有产品片的固定结尾。

### 同日V8补充：减少照片，以人的操作推动任务回应

本人在V7后明确反馈照片使用过多、仍像PPT、缺少互动与对人的理解；要求照片只在开头及关键处使用，反馈改为两张，并取消左上角Logo。本对象以本条覆盖V7“配入大量图片”的数量要求；深灰、米白、橙色视觉依据和有效课程内容继续保留。

- 主体用同一人物、对象或工作场景贯穿：人提供真实业务材料、选择与判断，Agent调用方法交回初稿，人检查并修正。人物、手部或光标的动作须与可见任务回应对应；人物装饰、框图平移、页面切换不能替代互动。画面中的操作示意须与真实软件、真实交付和效果事实分开标注。
- 照片收回到开头和少数关键证明段，逐项登记用途、出现次数和累计时长。不要在每个内容段固定配一张照片，也不把增加动画片段数量当作动作已经解释关系；保留整体模型、受众对应和证据阅读所需的稳定信息。
- 要求两张反馈时，选两张不同的原始上传图片，分别保留所选完整手机屏幕和上下文；不得只从同一张拼图裁两个屏幕便当作新增一张反馈。课程反馈、实践交流与账号数据分别辨认，不据此新增课程效果承诺。
- 本对象取消视频和配套封面的左上角官方Logo叠加；不影响原始课堂素材已有的来源文字。开头模型后接真实交付、正式履历、90秒内双画幅和指定联系结尾继续有效。
- 从实际导出的连续播放与前后帧核对“人做什么—系统怎样回应—人如何检查—得到什么”；对双光标、动作不对应、遮挡、裁头、缩小不可读和节奏停滞先修复，再交本人审看。技术播放不等于审美采用。

### 同日V9明确纠正：按剪辑Agent的PPT型动画制作

本人最新原话：“你说的都要修改，另外，整个视频还是类似PPT的播放，仍然不是动画。我需要的是剪辑Agent里的‘PPT型’的内容。”本对象当前绑定`animation_type=PPT型`，按[类型方法中的PPT型](动画类型与分镜方法.md)执行；覆盖V6至V8自行解释成必须故事型、同一人物或工作场景贯穿的要求。照片减少、无Logo、正式履历、联系片尾及其余有效内容继续继承。

- PPT型是结构化解释动画，不是静态PPT图片轮播，也不是仅继承PPT配色。按实际原声选择判断、对比、层级、流程、调用和反馈模型，图形随语义展开、聚焦、连接与返回；不以人物、手部、光标或虚构软件界面作为动画成立的前提。
- 复盘中“对人的理解”落实为受众处境与问题准确对应、具体关系易懂和结果阶段清晰，不自动转化为添加通用人物。不同信息结构分别构图，不能让长段都在同一电脑/界面里换字；同组并列主题同时保留足够阅读时间。
- 本人要两张完整反馈时，指两张完整聊天截图，不要求来自两个不同上传文件。允许从同一真实拼图分离两张完整手机屏幕，分别直接对应旁白引用；此前V8“独立上传文件”条件是AI额外增加，本条撤销。保留整屏和原上下文，不为凑两份文件改用较弱或无关证据。
- 已确认的颜色、字体和安全区与类型一起继承；横竖分别组织信息密度与字号，不将一版整体缩小充当另一版。先看实际代表片段与关键阶段，再导出和检查全片；已确认模板不重复索取类型或颜色许可。

## 锁定产品事实与范围

继承已确认名称、对象、问题、内容、交付、价格、边界与真实证据；产品表达材料由原主责提供，不为视频另造权益、目标客户或经营结果。记录`video_category=产品介绍视频`、触发原话、目标时长、横竖范围、动画类型和视觉依据。类别与故事型/PPT型是不同维度。单条明确要求优先，当前此类短版以90秒内组织，先压缩文案再按本人认可声音节奏制作，不能仅把长片机械加速或截断。

## 介绍结构与声音

1. 开头按企业/产品官方介绍：用一句话讲清这是什么、叫什么、面对谁、解决什么问题。配套先呈现整体课程/产品模型，再展开局部；不沿用知识短视频的痛点钩子或悬念开场。
2. 建立“整体价值与模型 → 受众处境与具体卡点 → 关键问题和解决机制 → 学习/使用过程与成果阶段 → 可信反馈 → 主讲人/团队与参与入口”的紧凑叙述，按实际材料取舍。首页模型呈现输入、核心能力连接和可带走的成果，不以堆节点体现系统性。缩短时合并同类问题，保留问题到解法的逻辑，不只剩模块名或宣传口号。
3. 主讲人介绍用第一人称“我”，自然说明实践来源、经验与希望帮助的具体事情。使用客观、谦虚的措辞，不逐条朗读画面上的title、履历或头衔，不宣称未经证实的效果。需要正式介绍时，画面展示姓名、已核实的正式身份与履历，与口头讲述互补；不因不念title而删除屏幕履历。
4. 先核对当前官网或指定品牌的主色、logo原资产与实际使用，不仅从旧视频继承配色。按本人要求建立商务层级、克制对比和低刺激模块配色，不用大面积高亮底色、亮白卡片和无层级色块替代设计。允许加logo时置于左上固定品牌区，保持原比例、识别性和安全间距；具体色值与尺寸绑定当前对象。
5. 背景音乐按本人本次明确方向制作或选取，独立保留、配合节奏并让人声优先。照片与真实课堂素材服务讲解和证据，模型关系由动画承担。用户提出该类视频与动画形式时才使用，不自动替换其他视频画风。

## 知识关系的模型动画

1. 为每处流程、层级、调用、输入输出或反馈关系建立“原话 → 对象及职责 → 关系类型 → 开始状态/变化/落点 → 配音时码”映射。不只让几个词轮流出现，不将所有知识点画成同一种线性箭头。
2. 工作流、Agent、Skill按当前知识依据呈现：工作流组织完整任务与阶段；Agent推进阶段结果并调用Skill；Skill承载具体方法。用阶段展开、调用与返回、产物交接等动作显示职责，不画成三者互相升级、转化或可以替换的关系。知识依据与标准检查按实际讲述接入，反馈有明确返回对象。
3. 复杂关系先总览，再放大一项观众能识别的实际任务；随讲述逐步出现职责与调用，最后收束为简洁整体。避免一开始铺满多行多列的Agent/Skill节点与重复连线，不以增加节点证明系统性。全部类似知识点按各自关系选择流程、层级、对比或模型动画；动作跟随配音，关系线有方向和含义。文字帮助辨认职责，不用大段逐字稿替代图解。
4. 可以参考本人已提供/已授权的PPT及课程页面模型；先核对文字与当前有效知识。旧课件含失效架构、历史数字或旧名称时重绘当前逻辑，不恢复旧事实。原PPT是参考资产，不必将静态图片逐页播放。

## 受众页与双版交付

1. 开头概括受众；整体介绍后尽早用一张稳定画面，把职业/行业关键词、岗位及阶段与各自具体问题一一对应。围绕“哪些人想把自己的专业做成Agent”组织，沿用有效来源，不凭空增加行业承诺。配音概括，画面对应“谁—卡在哪里—本课处理哪个环节”，避免只列职业、泛化痛点或直到片尾才出现受众。
2. 两种画幅分别安排模型、受众关键词、照片、字幕和咨询入口；保留同一语义和配音时码。时长、模型完整显示及关键词同时可读均以实际导出为准。
3. 上传的模型、聊天记录、案例或账号截图先逐项归档并判断对应产品和阶段，再选用。原图节选保持原句和上下文，区分课程反馈、咨询反馈、账号展示与经营数据；不把咨询或求职结果移作本课效果，不从播放量推导课程因果。可匿名截取必要区域并保留原图，不生成虚构聊天界面，姓名、头像和联系方式不作无必要展示。
4. 对照[执行标准](剪辑执行标准.md)检查实际文件。声音听辨、导演审美、工程交接和发布分别记录，技术检查不代替本人采用。返修只使真实变化项及其下游失效。
