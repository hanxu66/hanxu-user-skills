# 产品介绍视频｜官方介绍与模型动画

本文件维护产品、课程或企业官方介绍类视频的表达操作；是否调用由剪辑Agent绑定本人本次要求。它不是所有短视频的默认开头或默认画风，也不新增Agent或工作流。动画制作、声音、工程与导出继续调用动画视频制作（独立模式使用本次材料与本地记录）或[口播剪辑](../SKILL.md)，结果读[剪辑执行标准](剪辑执行标准.md)。

## 锁定产品事实与范围

继承已确认名称、对象、问题、内容、交付、价格、边界与真实证据；产品表达材料由原主责提供，不为视频另造权益、目标客户或经营结果。记录`video_category=产品介绍视频`、触发原话、目标时长、横竖范围、动画类型和视觉依据。类别与故事型/PPT型是不同维度。单条明确要求优先，当前此类短版以90秒内组织，先压缩文案再按本人认可声音节奏制作，不能仅把长片机械加速或截断。

## 介绍结构与声音

1. 开头按企业/产品官方介绍：用一句话讲清这是什么、叫什么、面对谁、解决什么问题。配套先呈现整体课程/产品模型，再展开局部；不沿用知识短视频的痛点钩子或悬念开场。
2. 建立“整体价值与模型 → 关键问题和解决机制 → 学习/使用过程与成果阶段 → 可信反馈 → 受众适配 → 主讲人/团队与参与入口”的紧凑叙述，按实际材料取舍。缩短时合并同类问题，保留问题到解法的逻辑，不只剩模块名或宣传口号。
3. 主讲人介绍用第一人称“我”，自然说明实践来源、经验与希望帮助的具体事情。使用客观、谦虚的措辞，不逐条朗读画面上的title、履历或头衔，不宣称未经证实的效果。画面可保留已核实的身份文字，与口头内容形成互补。
4. 背景音乐、本人照片、真实课堂素材和品牌颜色按本次授权及已认可样式使用；图片服务讲解和证据，模型关系由动画承担。用户提出该类视频与动画形式时才使用，不自动替换其他视频画风。

## 知识关系的模型动画

1. 为每处流程、层级、调用、输入输出或反馈关系建立“原话 → 对象及职责 → 关系类型 → 开始状态/变化/落点 → 配音时码”映射。不只让几个词轮流出现，不将所有知识点画成同一种线性箭头。
2. 工作流、Agent、Skill按当前知识依据呈现：工作流组织完整任务与阶段；Agent推进阶段结果并调用Skill；Skill承载具体方法。用阶段展开、调用与返回、产物交接等动作显示职责，不画成三者互相升级、转化或可以替换的关系。知识依据与标准检查按实际讲述接入，反馈有明确返回对象。
3. 全部类似知识点按各自关系选择流程、层级、对比或模型动画；动作跟随配音，关系线有方向和含义，最终保留清晰整体。文字帮助辨认对象和职责，不能用大段逐字稿替代图解。
4. 可以参考本人已提供/已授权的PPT及课程页面模型；先核对文字与当前有效知识。旧课件含失效架构、历史数字或旧名称时重绘当前逻辑，不恢复旧事实。原PPT是参考资产，不必将静态图片逐页播放。

## 受众页与双版交付

1. 开头概括受众；后段另用一张稳定画面同时列出适合的职业/行业关键词、岗位及阶段。围绕“哪些人想把自己的专业做成Agent”组织，沿用有效受众来源，不凭空增加行业承诺。配音概括，画面用并列关键词帮助识别自己，避免切成分散页面。
2. 两种画幅分别安排模型、受众关键词、照片、字幕和咨询入口；保留同一语义和配音时码。时长、模型完整显示及关键词同时可读均以实际导出为准。
3. 对照[执行标准](剪辑执行标准.md)检查实际文件。声音听辨、导演审美、工程交接和发布分别记录，技术检查不代替本人采用。返修只使真实变化项及其下游失效。
