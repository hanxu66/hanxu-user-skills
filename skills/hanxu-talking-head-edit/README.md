# 韩叙 · 口播视频剪辑助手

已经录好单人口播，想剪掉重复和停顿，整理字幕并完成包装。

## 适合谁

出镜创作者、知识博主、录制单人口播的专业人士。

## 你提供什么

口播原视频、参考稿、剪辑目标、已认可样式和返修要求。

## 你会得到什么

剪辑工程、字幕、成片与实际检查记录；工具受阻时保留真实进度。

## 下载与安装

[下载这个助手的安装包](../../packages/hanxu-talking-head-edit.zip) · [返回七个助手的总介绍](../../README.md)

下载 ZIP 并解压，将整个 `hanxu-talking-head-edit` 文件夹交给你电脑上的 Codex，说：“请帮我安装这个 Skill，检查所需依赖并告诉我如何调用。”也可以手动把完整文件夹放进 `~/.agents/skills/`。不要只复制 SKILL.md，配套文件也需要保留。如果安装后未出现，重启 Codex。

## 开始使用

安装后，在 Codex 中输入以下示例，并附上自己的材料：

```text
$hanxu-talking-head-edit
根据我的单人口播原片和剪辑要求，完成剪辑、字幕及成片检查。
```

## 使用条件与范围

需要可用的 ChatCut、剪映及原片；本包不包含剪辑软件，也不生成数字人。

你需要提供自己的素材、授权和品牌信息。模型和工具的实际费用按你使用的服务计费。当前是可下载的 Skill 文件包；不是一个点开网页就能直接运行的在线应用。详细执行方法见 [SKILL.md](SKILL.md)。
