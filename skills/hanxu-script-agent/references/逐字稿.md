## 独立用户的口播写作与返修

独立试用只执行本节及所链接的口播校准与正文复核操作；检查读[脚本执行标准第0节](脚本执行标准.md)。公司内部选题、AI主题、个人数字隔离、固定禁用句式和拍摄交接不属于本包。

1. 回读本题已明确的论点、论证、结构、来源、本题时长要求及本作者表达记录，先按下方“全文质量与时长检查”分配内容预算，再按[个人口播校准](个人口播校准.md)写完整正文。没有历史样本按当前原话、明确偏好和基础口语先写，在后台记录尚未校准，不用口头禅补风格。
2. 将抽象词讲成具体的人、动作、原因和结果，补齐听者需要的前提、因果和指代。应用有依据的本人措辞、态度和讲述习惯，保留结构及证明关系；不能为了亲切、紧凑或像本人删掉关键条件和收获。
3. 重新打开最终正文，完整执行下方“全文质量与时长检查”及“正文独立复核”的开头、逐段推进和实际收获检查，再按[个人口播校准的分流与回查](个人口播校准.md)逐项核对正文事实、数字与操作建议的本题出处；只有表达样本能支持的句段必须删除，不能把模糊化或改写当作解决来源问题。后台保留当前正文的简短复核记录：各段新增作用、需要收窄的断言及实际改句、本题预算与当前计数。复核时逐句引用实际稿件，特别核对首尾是否让观众重复做同一动作、猜测是否丢失限定、帮助意愿是否变成逐次兑现保证；不能用“整体顺畅”替代具体句段检查。任一项仍有缺陷就继续改，不只给自己打通过标签。结果按第0节判断；有Python环境时按[正文复核记录与校验](正文复核记录与校验.md)保存当前正文的引用记录并调用包内校验工具；无法运行时保留文字审读与能力限制，不假报程序通过。程序核对只证明引用和版本一致，不替代内容判断。
4. 默认回复只交一份可直接复制朗读的完整正文，按自然意思分段；直接从第一句开始，不加“逐字稿”等标题、段落编号、加粗、引用块或代码框，不插入“停顿、行动、转折、开场、收束”等标签、括号提示、表演动作和字数时长说明。原材料中的补充条件改成自然口语，不靠括号附注。论点、论证、结构、风格分析、改动清单、检查结果和作者记录在后台处理，不随稿复述；用户明确索要时才在该次回复单独展示相应内容；“按需查看”不是随稿追加说明的标题。读取材料、加载Skill、计数和检查不先发送过程前言，也不用英文先发执行说明；工具进度由宿主显示。发送前检查整条回复：从口播第一句开始，到最后一句结束，删去所有不实际朗读的前言与尾注。只有影响成稿的实质缺口才先作最小补问，不附惯例警告、版本菜单或重复的改稿邀请。返修按用户指定范围交稿，不为精简删掉正文必要的解释和条件。收到反馈再按[个人口播校准的反馈步骤](个人口播校准.md)处理；作者未确认不记录采用，交付后不强求拍摄，不自动删除旧稿。


### 全文质量与时长检查

- **写前定容量**：继承本题已有时长限制；新题不自动继承前题的两分钟要求。未指定时长时，按任务需要选择合适容量，不强行套统一长度。有作者已测语速时据此预算；没有时作为文字规划采用每分钟200个非空白字符、另留15秒停顿余量的保守估法，数字、英文和难读词须按实际读法增加余量。两分钟任务据此以约350个非空白字符为上限；其他时长按相同口径换算。初稿目标取预算的九成，给实际读法和返修留余量，不贴着上限挤字。这是预算，不是实测语速或真人时长承诺。
- **逐段去重**：用一句话概括每段新增的事件、证据、条件、解释或动作。重复交代同一背景、同义重说同一判断、反复安慰或多次升华而不推进时合并或删除。行动邀请也要按意思去重：正文和结尾让观众做同一件事却没有新增步骤时，只保留最合适的一处。短稿中的跨题旁证须直接证明当前判断且有足够解释空间，否则整段删去，不留下需要观众补背景的专名。同一判断先反问、后肯定，或换成情绪感叹再讲一次，也算重复；结尾已有具体行动时，不再复述前面的自我辩解。首尾呼应有实际收束作用才保留；不因换了词就视为新内容，也不为压字数删掉必要前提。
- **逐项校准断言**：按观点立意核对每项保证、普遍判断、因果及对他人的评价。成功个案、作者确信或愿意帮忙，各自保留其真实范围，不能推出人人成功、必然结果或无限回复承诺。对未来每条消息都回复、每个问题都解决之类承诺，改为有实际容量的帮助意愿或具体可做的动作；原文这样说过也不是保留理由。按实际句子的履行义务判断，不能在检查记录里把没有例外的回应保证解释成“安抚意愿”而放行；前面有“如果再发、等我看到”也只限定触发条件，没有限定每次都履行的承诺。确为意愿时正文直接说愿意、尽量，或只给出观众可以采取的动作，不替作者许下逐次回应保证。只降语气词却保留同一保证时继续改；原文的“可能、不知道、尚未确认”属于事实状态，压缩时不得丢掉、改成确定陈述；没有依据的他人动机删去或明确未知，不擅自改成作者认错。
- **按实际稿件复算**：具备文本计数能力时计数当前正文，按本题预算检查；超出时优先回结构删离题旁证、重复过程与第二次收束，再重写，保住唯一判断、必要依据与合理边界。不用“读快一点”满足时长，也不用短到失去意思的碎句。无计数工具时留更大余量，不凭印象报精确字数。正文改动后重新核对来源与纯正文交付；文字预算、实际朗读和音频时长分别记录，无实际音频不声称真人两分钟已通过。

## 正文独立复核

交付前采用以下实际检查方式，结果写入本对象现有应用／检查记录，不增加本人填表或人工闸门。先遮住标题、结构卡、分析解释，只凭当前口播正文完成复核；再回来源检查事实。这里的“独立”指退出写作过程重新检查，不表示另一个人或模型的独立验收。

1. 直接引用起句及必要承接，说明目标观众从这些话中认出了什么自己的处境、为什么值得继续听。作者曾做过的事不自动成为观众的普遍误区；判断依赖这种未经依据的前提时退回观点立意，不能只润色起句。
2. 从首段到末段逐段标记实际新增的疑问、前提、原因、证据或动作。必要的循环复现、指代和收束可以保留并说明作用；换词复述同一提醒、反复回到背景却没有推进时，指出具体句段，退回内容结构。检查的是作用，不按句长、重复词频或固定段数判定。
3. 从正文引用观众实际能带走的收获。方法／解释／纠偏任务检查起点、动作顺序和完成标准是否真的说出；观点／故事任务检查改变了什么理解或判断及其依据，不硬塞教程。关键词、命名方法或一句可复制指令是适用时的表达选择，不作为每条必需。
4. 本人对当前原稿的明确否定保留原话与对应文件哈希，即使旧收据曾通过也不能放行同一未改版本。新版本重新审读，不能把旧版否定无差别移到新稿，也不能把AI修订当作本人采用。只改文风的比较锁定同一结构与事实；完整成稿比较允许各自结构，但结论分开说明结构与文风的作用。
5. 按[正文复核记录与校验](正文复核记录与校验.md)在原对象记录中保存引用、逐段判断、实际收获和缺陷归属，调用现有状态交接前的正文记录校验。引用或覆盖不符修记录，语义缺陷修正文；不能靠把`fail`改成`pass`消除未修问题。通过只代表当前文字检查，听感、本人采用与平台效果继续分别验证。
