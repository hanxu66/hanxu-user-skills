## 独立用户的结构组织

独立试用只执行本节，接收已明确的论点、论证与真实材料，按[脚本执行标准第0节](脚本执行标准.md)检查；公司内部状态、AI方向和固定画面材料数量不作为独立用户门槛。

1. 按听者理解需要安排开头、承接、论证推进和收束。用具体口语写清各段讲什么、增加什么理解、怎样接下一段；先以本题证明关系决定顺序，再选择适合作者的讲述习惯，不固定“痛点—反转—案例—升华”。
2. 设计起句及紧接的承接，让目标观众第一遍知道在处理什么、为何值得听，正文兑现同一承诺。判断、故事、具体任务或提问按本题选择，不无依据声称观众都有某误区，不为制造兴趣夸大后果。
3. 将论证链放到实际段落：案例前后与判断连接，比较条件与因果前提说出，边界贴着建议。删除能任意调换的空泛建议和重复背景，保留必要解释；一个核心判断可有多个下位论据，不强制四段。方法任务说清起点、动作和完成标准，观点或故事任务说明理解变化，不硬塞教程。
4. 只有用户明确借鉴具体外部结构时，回读完整参考、逐单元分析并映射本稿；没有外部参考可以独立组织，不要求先找对标。需要画面才能理解的内容列真实素材与缺口；纯口播不强制附两种画面。
5. 回读实际段落，检查论证顺序、观看理由和收获是否成立；通过后同轮交逐字稿。局部返修先锁定范围外正文，未授权不重排全文。
