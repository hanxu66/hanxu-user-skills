# 正文复核记录与校验

审读动作只在[逐字稿Skill](逐字稿.md)维护，结果标准只读[脚本执行标准](脚本执行标准.md)。本文件只定义当前记录及命令。记录由执行者在原对象应用／检查文件中维护；本人不用填写。

## 记录

`objectId`可为使用者自己的本地名称，`version`与当前对象一致；`script`为实际文件路径及SHA256。文件有独立`## 逐字稿`章节时，只取该章节至下一二级标题之前的正文，标题、对象信息及非口播说明不进入证据；纯口播文本可直接使用。正文段落按实际空行划分，只为定位，不要求固定段数或句长。

```json
{
  "objectId": "当前对象",
  "version": "V1",
  "script": {"path": "script.md", "sha256": "实际SHA256"},
  "taskType": "method",
  "opening": {
    "quote": "从起句开始的实际连续原文",
    "audienceRelation": "仅凭该段，观众认出了什么与自己有关的处境",
    "verdict": "pass",
    "reason": "实际审读理由"
  },
  "paragraphs": [
    {"id": 1, "quote": "第一段中的实际原文", "adds": "这段新增什么或必要复现什么", "verdict": "pass", "reason": "实际理由"}
  ],
  "gain": {
    "quote": "实际收获所在的原文",
    "verdict": "pass",
    "reason": "为什么已形成具体收获",
    "start": "正文中的起点原句",
    "sequence": "正文中的动作顺序原句",
    "completion": "正文中的完成标准原句"
  }
}
```

示例只展示schema；`paragraphs`必须按实际次序逐段覆盖一次，每条quote取对应段中真实句子，可只引关键句。`taskType`按本次任务选`method/explanation/correction/opinion/story`。前三类通过时的`gain`引用`start/sequence/completion`；后两类通过时改用`judgment/difference`，分别引用实际判断及带来的理解差别。不得从后台材料补正文没说的动作或收益。

各项`verdict`为`pass/fail/unknown`；失败或未验证项另写`returnTo`，取`观点立意/内容结构/逐字稿`中的真实缺陷归属，并在reason具体说明。工具根据这些实际判断汇总整体结果，不接受写作者另给的总PASS覆盖失败。

本人已否定本稿时，保存`rejections`列表，每项含带路径／SHA的`evidence`、其中的真实`quote`、被否稿件的`scriptSha256`、`reason`及`returnTo`。旧稿没有改动就不能标成已解决；改了真实正文的新稿重新复核，旧版反馈用于检查是否修好，不能不加区分地作为新版否定凭证。只保留必要反馈证据，不将私有案例或反馈放进分享包。

## 校验和接续

```bash
python3 scripts/check_short_video_script_review.py --review 当前应用记录.json --output final-body-check.json
```

独立安装使用包内`scripts/check_short_video_script_review.py`。相对路径以review文件所在目录解析。退出0为当前记录引用、逐段覆盖和审读结论一致，1为语义审读有失败／未验证项，2为输入、证据或覆盖错误。失败结果给出实际引用、原因和应返回阶段；输入错误也会将旧绿灯输出替换成失败。不得将输出指向原稿或审读输入。

内部接力继续使用原`script_ref/final_check_ref/style_application_ref`，`final_check_ref`指向上述输出，版本与对象绑定。工具会重读审读输入、正文与反馈SHA；缺证据、漏段、伪引文、旧稿或被否定的同版本不能提交`脚本完成`。独立用户不调用公司状态工具。

新提交的脚本状态带`scriptReviewPolicy=actual_body_v1`。旧对象的历史状态不批量改写，也不冒充已通过新检查；旧稿恢复写作或返修后再次提交`脚本完成`时，同样须有当前正文复核。现有工程、拍摄和发布事实不因本次检查升级被重做。

这里没有用关键词或模板判断稿件好坏：语义由执行者按当前标准实际审读，程序只检查证据、覆盖及版本是否支持该判断，并执行失败关闭。同一执行者重读不构成独立／盲测；旧问题被拦截只证明这次回放成立，不能宣布所有新稿或平台效果已验证。
