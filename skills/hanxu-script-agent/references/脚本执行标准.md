## 独立使用的配置边界

独立用户沿本文件的方法与检查，以自己的已确认任务、原话、真实材料及输出目录执行。使用者身份、业务主题、样本库、专名纠正表、品牌及字幕/字体/美颜/美体/速度/音量数值仅属于使用者自用配置；其他用户保持自己的原片/原工程值或本次明确选定值。没有个人历史样本时校准本轮原话，不虚构过去的修改和效果。不调用公司状态库、自动化或私有客户资料；各阶段凭证保存用户本地记录。

# 脚本执行标准｜怎样才算做对

本文件只定义观点立意、内容结构和逐字稿结果怎样才算正确。操作步骤只读当前Skill；阶段路由、状态、返修和人工闸门只读[脚本Agent](../SKILL.md)。

## 使用方法

- 每个大步骤前先读本文件对应章节，再读当前Skill本步流程；完成后复读同一章节检查真实产物。
- 结论只写`通过`、`失败`或`未验证`。字段齐全、写过一版或能概括主题都不能代替实际内容通过。

## 题面调研来源的脚本边界

元数据调研来源只提供问题、角度与题面启发，不提供作者完整观点/论证/结构。已选题依据本人已确认判断、真实材料形成立意并独立设计本稿结构；未因原视频没有全文否决可完成的自己内容，也未从标题虚构作者内容。以下完整对标/部件组装判定仅在本次明确使用真实完整参考时适用，不能自动恢复为题面找题或所有写稿前置。

## 1. 上游输入标准

- 当前对象具有一张状态为`已选`且通过当前选题标准（独立模式使用本次材料与本地记录）、含阶段方向复核的选题卡。本人观点与外部对标来源的受众、主判断、反认知、证据、边界与用户收获可回读；平台检索型来源的种子词、检索词、代表视频、点赞兴趣信号、目标人群、具体问题和使用者选择证据可回读，主判断、证据、边界与用户收获在观点立意阶段形成。
- 外部方案的`protected_core`、`protected_structure`、模式和分部件来源可回读；结构和逐字稿兑现当前方案。本人明确修改主判断时新版本已重新通过准入和结构检查。
- 平台检索型题面不证明观点；生产模式已取得完整外部来源后可以采用其观点与结构，不默认等待本人新观点，不能从点赞推断内容。
- 公众号改编具有真实全文和阅读卡，原文核心、证据、作者归属与短视频应用对照可回读；长文发表或曾经采用不代替本稿标准。
- 选题、立意、结构三个阶段按顺序推进；可以同轮连续完成，但不得合并字段、越级或先写逐字稿占位。
- 候选已有研究、核心锁定和可用证据已真实接收；最终立意明确其实际用法和边界。没有为了阶段形式重做来源搜索，也没有因复用材料省略必要的回读、证据补足或验收。

## 2. 观点立意标准

- 立意明确写出`观众原来的理解 → 使用者的新判断 → 核心证据 → 成立边界 → 用户收获`，五项均是可直接讲清的话。已选题的具体问题和题面预期收获能对应到本条判断、证据及用户收获；作者经历、成果或工具名称进入本稿时，实际说明了它对这个用户问题的解释作用。只把选题换个说法、把“值得讲”当作观点，或只有作者总结却不能回答已选问题，不通过；证据或本人修改确需调整预期时有真实依据并按原返修边界处理。
- 五项使用日常、口语化表达，能说明谁在做什么、为什么会这样；不能靠专业标签、箭头提纲或抽象分类让听众自行补前提。
- 全片只证明一个核心判断；反认知来自真实差异，不靠“其实／反而”制造表面冲突。
- 只看口播正文，目标观众能用一句日常话复述本条判断，且能说清理解或下一步判断改变在哪里；只有一个主题名称、相关概念或数条正确建议，不算观点聚焦。观点型内容的增量要落在常见理解遗漏的原因、条件、关系或取舍上；把已反复讲过的提醒换成AI术语、换案例或多列步骤，不自动获得新认知。实用方法型内容可以靠明确的新用法与可用结果成立，不强迫每条制造反常结论。依据：本人集中度、独特认知与收获反馈（独立模式使用本次材料与本地记录）。
- 核心证据来自可追溯的使用者或学员事实，并直接支持同一判断；外部作者案例不进入成稿。
- 核心论证有一件可核对的本人或学员真事，能说明当时在处理什么、具体卡在哪里、采取了什么动作及目前发生了什么变化；不能用“比如你擅长……”等一句泛例或方法文档代替已经发生的过程。开发选择、真实反馈、失败与返修也可作为案例，不要求新成功或成交。学员自述保留归因，方法建议与实际执行分开。
- 最强反例和不适用条件已写明。与本人明确立场冲突或缺少证明时返回选题修订当前方案；本人明确改变观点可生成新方案，不能暗改核心后仍宣称完整继承原作。

## 3. 内容结构标准

- 可复用结构具有整体顺序、段落功能和句子／气口动作三个层次；逐单元原文与位置可回读。详细记录能说明每个动作要接住什么疑问、补哪一步解释或证据，以及怎样连接下一动作，不能仅用四五个阶段名冒充完整结构。
- 结构精细程度以可理解、可迁移和实际适配为准，不以步骤数量或拆分更细自证有效；细节仍服务同一主判断，不把完整结构压成固定步数。

- 对标来源的完整口播已经逐单元覆盖；没有漏句、重复、跨标点合并或用摘要冒充原文，单元的作用与前后承接可核对。
- 各类来源均具有清晰入口、承接、唯一主判断、有效证据链、连续推进和收束。选题承诺及立意中的用户收获，在本稿具体开场、解释/证据段和收束中有可回读的兑现位置；只有后台写了收益、口播仍停留在泛机会或作者成果罗列，不通过。`一个问题 → 一个判断 → 一个证据 → 一次收束`是集中度检查，不是固定四段顺序；同一判断所需的多个下位论据和必要解释没有被机械删除。
- 前约5秒让真实受众知道这条内容与自己有关，并指向同一核心判断；开头后的句子接住误区、后果或自然疑问，不跳到第二个主题。
- 纠偏型或反认知内容在开头之后已经把误区写成完整处境：观众误以为什么、因此做了什么、过程中增加了哪些返工／等待／选择，以及这些动作带来什么有处境支撑的痛点或感受。只写“很累／很焦虑／效率低”或直接跳到抽象原因，不通过。
- 每段写清具体讲什么、作用、怎样接上一段和引出下一段；并列、因果、解释、例证与转折没有混淆。
- 正文每句对同一判断有可解释的推进作用：提出下一疑问、补前提、解释因果、提供证据或引出下一动作；不能只是把数个相关建议并列。案例所占比重与其证明任务相称，不能在观众已理解或不关心的地方反复铺陈；该标准不等于机械缩短，必要的机制解释、本人依据和自然承接应保留。
- 解释型、纠偏型或方法型内容具有观众可以直接带走的具体收获：正文说清一个做法从哪里开始、按什么顺序执行、用什么标准判断完成，并在适合时给出可照着使用的问题、检查项或例子。只解释现象、只讲原则或只给泛化建议，即使观点正确也不通过；具体做法仍须服务同一核心判断，不以堆技巧制造收获感。
- 结构卡本身已经能顺着讲明白，不需要到逐字稿阶段再翻译专业词或补齐逻辑；原概念确需保留时具有口播中的真实归因。
- 案例前说明要证明什么，案例后扣回判断；结尾完成收束，不开启第二个问题、第二个建议或第二次价值升华。
- 案例不是插入一段背景介绍：具体材料、动作、选择、转折和当前结果共同支撑本条判断，观众能跟上过程。烦躁、焦虑、生气及具体对话有本人原话或确认依据；没有依据时只写可核对的处境与动作，不人为添情绪。当前批次反复使用同一案例时，须有真实不同的论证用途；不能只是换题名重复干讲同一次规则调整。
- 本轮成稿有与核心过程相对应的可选画面方案，至少两种可替代材料，说明画面显示什么、证明什么、已有还是待补。图片未提供时保留素材待补状态，不声称画面或声画效果已经验收；不能把截图承诺当作已取得素材。
- 内容容量与呈现负担匹配当前短视频：必要画面能让人看懂本条核心过程，不要求观众追随过细的执行步骤，或靠大量精细剪辑补救口播中未讲清的观点。依赖成品或操作对照才能理解的小工具、制作类稿，具有可核对的真实已完成案例及其展示交接；仅文字说明或一份截图计划不能标为可直接纯口播拍摄。缺展示素材时标待案例，保留已确认稿；低价值、审美疲劳或制作负担超过收益的个案退出本轮，不据此永久禁止工具题。依据：本人案例与可视化成本反馈（独立模式使用本次材料与本地记录）。
- 只改开头等局部返修时，范围外内容与有效检查点保持不变；必要扩改有明确冲突和最小影响范围。

## 3A. 标注反推的开头要求

依据当前开头样本分析（独立模式使用本次材料与本地记录），评价对象是起句及紧接的一至数句形成的连续意思，保留原展示窗口；不是孤立第一句，也不将整段高分当实际前5秒已通过。

- **观看理由清楚。** 目标观众能理解与自己有什么关系，想看下去是为得到结果、学到做法、解开疑问或理解有用的差别，不只因为句型夸张、术语新、作者或第三方有名。
- **开场要展开，白话不等于简短。** 按本题需要把起句和后续几句连成一个意思，用熟悉的处境、具体动作及后果、本人判断或客户视角追问，让观众更想知道原因和做法。不能只凭一句顺口提问就认定开头通过，也不能问完就急着抛抽象方法。展开的每句要推进认识，不为凑长度重复情绪；不统一字数、句数或强制所有题先制造痛苦。依据见本人六个示范及学习记录（独立模式使用本次材料与本地记录）。
- **保留本人的口吻与态度。** 有依据的直接判断、情绪、批评和反问可作为开场的一部分，不自动改成温和的一问一答；也不把某次强语气变成每条必需。本人示例中的受众处境、本人经历和观点分别归因，新稿仍按事实边界和长期句式要求组织。
- **第一句是能脱口而出的大白话。** 遮住标题与后台卡片，单听起句就知道在讲哪件事、与自己有什么关系；实际文字不能靠“能交出成果的工作”“最该验证的问题”等压缩分类让听众自行翻译。用具体任务、熟悉困扰或真实事件建立兴趣，紧接的句子开始展开；只缩短字数或替换近义词不算修复。本人本轮反馈（独立模式使用本次材料与本地记录）。
- **熟悉痛点可以直接吸引。** 以白话说中多数目标观众的具体困境，如“播放量两三百”，不能只因问题或解释较常见就降为及格；推翻根深蒂固的认识、广泛相关且有明确指向的好奇，也可独立构成观看理由，不必同时具备痛点与反转。开头负责建立观看理由，不要求在展示窗口内完成正文的全部论证；正文真实性与兑现要求不放宽。第四轮原分及边界见开头校准页。
- 情绪、讽刺或对话效果依赖声画时，文字判断与实际演绎判断分开；只看稿不能宣称已评价完整表演，不把训话语气或句式单独当0分规则。
- **具体且可接近。** 能听明白做什么、能得到什么；可以直接提任务、给方法承诺或清单，不必强行反转、反问或先渲染危害。实用痛点只证明相关，不自动达到“好”，还需让观众感到结果值得获得、方法可接近或疑问值得解开；对此有分歧时可用相近评分原文校准。
- **前句与承接共同成立。** 起句引出什么处境或疑问，后续就展开同一问题：具体动作和后果、值得追问的原因、本人判断或可信的交付预期均可推进，不要求下一句立刻给答案。不能反复吊胃口却不增加认识。正文兑现同一承诺，不用泛收益掩盖窄用途。
- **表达形式可选，不是固定配方。** 当前可参考真实成果→可学方法、直接需求→低门槛做法、想要的结果→好奇差异、具体纠偏→解释区别、成长/熟悉类比→当前问题。每一种都有低分反例，不能把形式名称当质量证明；两个3分样本不推出人人必须有大成绩。
- **禁用固定反转句式。** 标题、开头及后续对外文案不得使用`不是A，而是B`及其同构变体。反认知仍须提供值得知道、会改变判断的具体差别，但用直接判断、原因与结果、条件对比或两个自然短句表达；不能只把关联词换成近义词继续保留同一生硬结构。普通直接句不因没有反转被降级。
- **本人出现有用途。** 第一人称、故事和较长开场均可成立，关键是实际经历如何连接观众收获；不硬禁“我”，也不以字数、数字大小或名气加分。对照只有作者动态、无明确收获的低分例；本人单人口播默认不使用未适配的画外音设问。
- **吸引与可用分开。** 原样本吸引力/偏好、事实来源可信度、本人能否讲/拍分别有结论。无本人成果、依赖别人的身份、违背公开数字边界或存在夸大保证时，换材料或开头，不改原始高分；高分不豁免真实表达、归因与正文证据。
- 选题与开头分别判断：题2分/开头0分可以留题重写，题0分/开头2分可借局部方式但不解除题材准入。开头偏好不等于使用者全文文风，不能替代本人修改稿和实际口播。

## 4. 逐字稿标准

- 稿件与已选题、立意和结构一致，围绕一个问题、一个判断、一条核心证据链和一次收束；没有偷偷换题或新增独立命题。
- 标题、封面文案和发布介绍面向尚未看视频的观众，不默认其已认识视频中的人物、事件、指代或背景；脱离正文也能理解所指的问题与观看理由。封面可以比正文更概括，但须明确指向一类人群的真实痛点，承诺仍有本条内容依据，不靠泛化夸大事实。依据见0054本人反馈（独立模式使用本次材料与本地记录）。
- 后续新写或返修的标题、第一口播句、逐字稿正文、字幕文案、封面文案和发布文案，均不得使用`不是A，而是B`及其同构变体，包括`并不是A，而是B`、`不是因为A，而是因为B`、`不只是A，而是B`。对比关系改成直接判断、因果、条件比较或两个自然短句；只替换关联词仍判失败。历史已发布或已归档内容不批量改写，尚未发布的活动稿在返修、恢复生产或再次交付前重新检查。依据见使用者长期要求（独立模式使用本次材料与本地记录）。
- 第一遍能听懂并可自然朗读；关键句能说清谁、在做什么、为什么、意味着什么，不要求听众翻译内部术语或抽象分类。
- 第一口播句脱离标题仍自然、顺口且能一次听懂；一句只承担一个主要关系，不用多层修饰、书面倒装或必须听到句尾才能回头理解的问法。标题可保留信息密度，但不能未经口语改写直接充当绕口的第一句话。
- 句间连续，前约5秒兑现结构；必要主语、前提、因果和指代完整，没有靠“所以／然后”或堆语气词伪装口语。
- 案例、对话、感受、动机和结果都有来源；假设明确标为假设。使用者及学员真实业务规模和经营数字没有进入公开口播。
- 对标来源没有复制原标题、连续原句、作者案例或专属概念；必要引用在口播中真实归因。
- 合适对标的选题、判断、结构功能顺序与论证方法可以继承，不要求每稿另创核心。文字改动比例不构成不抄袭、不侵权或平台原创判定的安全线；不得以“改40%”或相似度分数放行。具体表达已按本稿事实与本人表达重新组织，不是逐句同义替换；具有独创性的具体表达或编排不能仅因标作“结构”而视为可直接复制。必要引用符合适当引用条件，超出合理引用范围的受保护内容有相应授权，署名本身不代替授权。
- 口播归因明确区分外部作者的原观点与使用者自己的解释；用户举例、内部来源字段或文件链接不能冒充口播归因。
- 最终只保留一个当前版本；未真实朗读或生成音频时，不声称真人听感通过，未发布时不声称提升完播。

### AI内容与本人真实表达

- 最终稿仍兑现选题卡的AI应用与读者收获，AI改变了实际解法、判断或结果；没有写着写着回到非AI旧话题、个人履历展示或产品推销。实质改动核心问题、判断、收获或入口后，当前选题准入重新有效。
- 活人感来自有来源的本人选择、试用观察、工作细节与反应，不靠端着讲概念、编造第一人称亲测或堆语气词。积极、健康的呈现不要求自曝负面经历、家庭隐私或制造冲突，也不允许伪造成功。
- 本人真事承担核心论证，正文展开实际处境、做过的事和变化，不能只剩清单、框架及一笔带过的案例。事实足够但讲法仍干涩时，返回结构展开过程；事实不足时保留最小缺口，不先编一个顺利完成的故事。写稿要求只作用于已选后的生产，不恢复为选题入围前置。
- 可用真实演示、操作产出或工作现场辅助证明时，拍摄说明能指出素材与用途。正文能独立讲清时，缺辅助画面不阻止诚实口播；理解依赖展示案例时，按内容结构的呈现要求标待案例，不把纯口播承诺当展示已齐。不强制改成Vlog或补拍隐私场景。价值观通过与当前问题有关的取舍体现，不每条加人生宣言。

## 4A. 学习应用标准

- 新写或修改的开头按3A及结构、逐字稿标准检查实际文字；正常生产不强制检索评分样本或填写评分样本ID。标准边界不清、与本人判断有分歧或明确校准时，才回查已标注样本（独立模式使用本次材料与本地记录）；实际使用时保留当前修订、原文、原分、备注、适用差异和采用位置，未命中不补造。开头偏好、选题准入、本人材料适配分别判断；不照搬外部身份／成绩，不把开头评分当全文质量、本人文风、音频核验或平台效果评分。原标注与AI归纳分开保存，负例未因不采用而删除。
- 结构应用记录能逐项对应来源／资产、结构功能、本稿具体段落及保留或调整理由；只写“参考过”不通过。完整对标的有效顺序未在套模板时丢失，分部件组装能连续证明同一判断。
- 文风应用记录引用本人修改／实际口播的具体版本及证据，说明当前稿哪些句段应用了哪些学习；AI草稿不作为本人文风样本，旧样本中的事实与业务数字不能不经核验进入新稿。
- 本人问题解决材料能追溯到确认判断、真实场景／案例或方法原文及版本／日期，实际用途与当前问题、条件相符；用于本稿的句段可回读。旧解决方法未被当作无条件有效的新事实，没有为使用旧材料擅自替换已锁定主判断；缺口与假设明确，未编造本人经历。
- 没有匹配资产时记录真实检索范围、未命中原因和当前结构／表达依据，不得伪造调用ID；现有明确相关反馈没有被无理由忽略。
- 改稿比较至少区分主判断、开头、推进、证据、措辞、节奏和收束；字符差异比例说明口径、样本分母和局限，不等于作者改稿工时或语义贡献比例。未收到修改稿不得报0修改。
- 本人明确长期要求可直接编译；个案、工作假设和稳定规律的证据层级明确，采用证明表达适配，平台效果需真实可比数据。
- 开头批次学习符合标注更新共同完成标准（独立模式使用本次材料与本地记录）：保存、归纳、反例、旧规则取舍与实际更新缺一不可；新评分没有凭空成为模型训练或效果验证。具体开头判定只由本文件3A负责，不以选题分或另一份分析代替。
- 观点、论证、结构与文风的校准同样遵守上述共同标准的跨模块来源去重及质量层次要求；完整上下文仍要保留，但不因此反复让本人评价同一材料。校准改稿与生产终稿分别保留，界面选择改稿B不自动覆盖已确认拍摄稿。

## 5. 状态、交接与返修标准

- `结构完成`具有可读取的`structure_application_ref`，`脚本完成`具有可读取的`style_application_ref`；工具只检验文件与字段，业务标准核查实际应用。
- `立意完成／结构完成／脚本完成`各自引用真实当前产物和阶段末复核证据；上游证据缺失不得进入下游。
- 自动接力返回可继续时，下一Skill同轮实际开始；真人口播的`脚本完成`进入拍摄人工闸门，不冒充`已拍`；动画稿已获本人采用／制作授权时直接交剪辑Agent，未确认稿先等待采用，不要求真人拍摄。
- 最后一次检查重新打开最终稿、已选题、立意、结构和来源；不能用写作过程记忆或关键词命中自证。
- 缺陷退回真实所属Skill，下游结果按影响范围失效；被否定或替代稿件关闭并清理，真实采用稿与拍摄事实保留。
