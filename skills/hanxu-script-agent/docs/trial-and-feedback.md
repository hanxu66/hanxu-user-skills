真实客户端试验仍使用虚构作者与反馈：它验证软件中能否执行这些动作，不是目标用户试用结论。首稿审读发现过内部固定格式带入、材料外细节及过强推断；已据此修正导出/核对方法并完成返修。因此使用时仍须本人核对判断、事实与表达，不以程序PASS代替审稿。

模拟输入不是客户案例或真人评价；AI重新审读也不是另一位真人的独立验收。[演示页](examples.md)另为文档编写的虚构示例，不计入验证样本。

## 建议怎样试用一次

选一个真实要讲的题目，提供自己的判断和依据，拿到完整稿后挑一两句不会说的话修改。再用另一条新题，检查是否能沿用合适的表达偏好，同时保留新题事实。

可以观察：作者是否愿意这样讲；论据有没有真正支撑判断；听者能否复述核心意思；局部改稿有没有牵动无关内容。没有必要为试用先发布视频，也不用把“满意”推断成平台效果。

## 提交反馈

可以在 [GitHub Issues](https://github.com/hanxu66/hanxu-user-skills/issues) 提交问题，也可以先把以下模板留在自己目录。不需要提供私人语料库、完整客户信息、账号凭据或支付信息。

```text
【版本】SOURCE.json里的构建版本；用户试用版v0.1.1
【使用环境】Windows/macOS版本；AI工具与版本；是否能读写文件、运行Python
【这次想完成什么】题目、给谁听、希望保留的判断
【输入类型】本人历史样本／本轮对话／没有样本
【具体问题】哪一句或哪一步不对
【我的说法】原句 → 我会怎么说（有则提供）
【修改范围】只改措辞／改结构／改论点或论证
【适用范围】仅这条／本人长期偏好／暂不确定
【预期与实际】想得到什么，实际得到什么
【可公开材料】只贴必要且已脱敏的片段
```

如果问题出在安装、文件缺失或校验，附错误文字和相关版本即可。文风问题优先给成对句子及自己的改法；“不像我”可以作为反馈起点，再具体指出不适配位置。不承诺固定回复或更新周期，修复与调整按实际反馈和证据推进。
