# 怎样提供语料，怎样逐步校准

[返回介绍](../README.md) · [快速上手](quickstart.md) · [演示](examples.md)

## 有自己的语料

可以提供以下任一类，不要求先整理成大语料库：

- 你实际说过的口播或直播转写，保留必要前后文。
- 你亲手改过并认可的稿件；有原稿和修改稿时可以同时提供。
- 你围绕当前话题自然讲的一段话，或当前对话中的原话。
- 自己写的文章也可作为补充，但文章表达与短视频口播需要分别适配。

优先选你认可、愿意在类似场景继续使用的表达。长材料可以分批给，要求执行者说明实际读了哪些；读取片段只能形成相应范围的观察。错字、重复重启和直播互动不必专门清洗，但已知的转写错误可以注明。

```text
作者称呼：【可用化名】
样本类型：【本人实际口播／本人修改稿／当前自然表达】
样本正文：【保留一段完整意思】
我认可的部分：【有就写，没有可以不填】
不想延续的表达：【可选】
本次公开边界：【哪些内容不可写入新稿】
```

样本里的数字、案例、产品、人物和观点属于原场景。新稿是否能用，要看本题事实与公开边界，不能因为“我以前说过”就全部沿用。

## 没有历史语料

直接讲这次想说的事即可，例如：

```text
我没有以前的稿子。这个问题我想了很久，我最想告诉对方的是……
我会这么想，是因为……
我不希望写成……那种口气。
```

这些当下原话已经能提供初始线索。已有观点、受众和依据时，可以先写基础口语稿；你再挑一句不会说的话，改成自己会说的话。没有样本不妨碍梳理内容，但不能据此声称已准确掌握你的全部风格。

## 学的是什么

| 层面 | 学习和校准的内容 |
| --- | --- |
| 论点 | 本题你想表达什么、确信到哪一步；不会仅从旧样本推定新题立场 |
| 论证 | 你习惯怎样解释和举例；具体材料仍须真正支持当前判断 |
| 结构 | 适合本题的进入、承接、推进与收束；不照搬一套固定反转模板 |
| 文风 | 态度、称呼、具体措辞、完整句与节奏，以及不愿使用的表达 |

通用质量要求与个人偏好分开：事实有依据、听者能跟上是共同要求；态度强弱、是否爱反问、用哪种叙述习惯需要本人材料和反馈。不会把维护者的经历、口吻或业务限制自动设成你的配置。

## 作者表达记录怎样形成

记录会区分三种状态：

- **本人明确要求**：例如你说“以后尽量用邀请式表达”。
- **样本支持的观察**：例如两段材料中都用具体比较解释取舍，注明出处和适用场景。
- **待验证猜测**：目前看起来可能适合，但尚未经本人认可。

“这句更顺”先作为本次修改；明确长期要求或有反复证据时，再写入持续使用的偏好。执行者应保存实际改法，不只记录“更口语、更有温度”等抽象标签。

下面只是记录形式示意，不是用户档案或已经学习到的规则：

```text
作者称呼：示例作者
明确偏好：尽量用邀请式表达（附本人反馈来源）。
局部观察：喜欢先比较具体动作再做选择（附样本原句；适用比较题）。
仅本题：保留当前故事结尾；不推广为所有题的结构。
待验证：新题是否也适合这种开头。
样本与反馈索引：记录用户本地文件位置和版本。
```

## 哪些材料不能算本人风格证据

喜欢的其他博主作品只能帮助说明审美偏好。未经你修改或认可的AI稿，不自动成为本人风格正例。一次“可以”不等于接受整套风格；几段文字也不能证明已学会实际音色、语速或气口。

## 材料保存与公开

作者记录与原始材料留在你的工作目录，Skill不执行对外上传或公开操作。模型如何处理你提供的内容，仍取决于你所用的AI服务和账号设置，不能把本地文件保存理解为全程离线。

只提供有权使用的材料，客户或他人信息先按自己的公开边界脱敏。反馈问题时可以只给必要句段和匿名示例，不必上传整份私人语料。
