## 演示一：没有历史语料，从本次想法开始

### 用户输入

```text
$hanxu-script-agent
我做画画体验课，没有历史语料。
我想给第一次来画画的人讲：线条画偏了，可以先留着看一眼，再决定怎么改。
演示用经历：我上次画杯子，杯口画斜了，没马上擦掉。放着看了一下，发现左右两边高度不一样，之后才动手调整。这里只讲这一次的发现，不说改完一定好看。
我平时话不多，别写成训人的口气。请用这些材料写短口播。
```

### 按需查看的后台说明：论点与论证

核心判断是“画偏以后，可以先观察偏差再决定如何修改”。依据是作者这一次先看后改的过程，能解释为什么值得留出观察时间；不能证明所有画偏都来自同一个原因，也不能承诺画得更好。

### 按需查看的后台说明：内容结构

从新手遇到的具体动作进入，接这一次经历，再收回到“看清偏在哪里后再改”。不额外制造“新手都急躁”的普遍判断，也不增加第二个教学主题。

### 完整口播稿

刚开始画画，线条画偏了，可以先留着看一眼，再决定怎么改。

我上次画一个杯子，杯口画斜了，先没擦。放着看了一下，发现左右两边高度不一样，之后才动手调整。

对我这一次来说，先看一眼，让我知道要改哪里。下次再碰到画偏的地方，也可以先看看具体偏在哪儿，不用急着把它全擦掉。



### 用户提出口吻修改

```text
“不用急着把它全擦掉”听着还是像提醒，我会说“看清楚了，再慢慢改”。
这次只换这一句，前面的事实、论证和结构都保留。
以后尽量用这种邀请式的口气，但别每段都来一句。
```

### 修改后的完整稿

刚开始画画，线条画偏了，可以先留着看一眼，再决定怎么改。

我上次画一个杯子，杯口画斜了，先没擦。放着看了一下，发现左右两边高度不一样，之后才动手调整。

对我这一次来说，先看一眼，让我知道要改哪里。下次再碰到画偏的地方，也可以先看看具体偏在哪儿，看清楚了，再慢慢改。

这次只替换了指定结尾。作者记录保存“尽量用邀请式口气，但不要反复提醒”的长期偏好及本人改法；杯子经历属于本题材料，不自动搬到下一条。

## 演示二：已有本人样本，学习表达后写新题

### 用户输入

```text
$hanxu-script-agent
我是摄影师，想给第一次约拍的人讲：拍摄前先确认要交哪些照片。
下面是虚构演示中的本人样本：
“我会先把这件事摊开看。我们各自想要什么，写出来以后就比较好商量。”
“我不急着说哪一种更好，先看看它们分别需要做什么，再决定。”

本题演示材料：我准备在拍摄确认单写清拍摄主题、交付照片的类别，以及是否包含精修。这份确认单还没用过，不要写成已经避免了争议。
请学表达，不搬用样本中的任何旧事实。帮我把论点、论证、结构和口吻一起处理。
```

### 按需查看的后台说明：论点与论证

判断是“约拍前把交付内容说具体，双方才有共同讨论的对象”。通过“拍摄主题、照片类别、精修范围”的具体差别解释它的作用；这是对确认单的用途分析，尚无使用结果。

### 按需查看的后台说明：内容结构与表达应用

从约拍任务进入，列清需要确认的对象，再解释这些对象为什么影响双方预期，结尾停在共同核对清单。借样本中“一起看具体事情再做选择”的表达习惯，不强行重复样本开头。

### 完整口播稿

第一次约拍，拍之前可以和摄影师一起看一张清单：这次拍什么，要交哪些照片，哪些包含精修。

我准备把这些写进拍摄确认单。它还没用过，所以现在只能先说，我希望双方在拍之前，把要交的东西谈具体。

比如，同样说“交一组照片”，有人想的是选好的照片，有人还期待每张都做精修。把照片类别和精修范围分别写出来，大家才知道正在商量什么。

确认的时候，可以一起对一遍：你想要的内容有没有列进去，哪些包含在这次安排里，哪些需要另外商量。先有这份具体清单，后面的选择才比较好讨论。

样本支持的是温和比较、具体说明的初步观察；“比如”后的场景是解释性假设，没有写成发生过的客户争议。是否像本人仍需作者反馈。

## 第二个新题怎样接着用

```text
$hanxu-script-agent
请回读同一目录的作者表达记录。
现在想讲另一条：【新题目】；新事实是：【新材料】。
沿用适合这一题的表达习惯，不要沿用上一次的故事、交付安排或结果。
```
