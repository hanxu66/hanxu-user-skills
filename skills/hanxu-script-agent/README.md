# 韩叙 · 短视频口播文风助手

用户试用版 v0.1。把你的想法整理成讲得清楚、适合你说出口的短视频口播稿，包含论点、论证、结构和文风。沿用原短视频写稿助手的安装标识 `hanxu-script-agent`，更新时替换同名文件夹即可。

## 适合谁

内容创作者、知识博主、需要出镜表达的专业人士。

## 你提供什么

本次想讲的题目、目标观众，以及自己的看法或相关材料。已有的信息不用重复填写，观点还不清楚可以先对话梳理。

表达样本可选。有本人口播、直播转写或亲手修改稿时就学习样本；没有历史语料时，从当前对话和你对稿件的修改逐步校准。不想提供样本也可先按明确偏好写基础口语稿，个人口吻仍待确认。

## 你会得到什么

核心论点及证据与证明范围、内容结构、完整口播逐字稿，以及可纠正和复用的个人表达记录。可以只要求展示正文，其他依据保存在任务文件中。

## 下载与安装

[下载这个助手的安装包](https://github.com/hanxu66/hanxu-user-skills/raw/main/packages/hanxu-script-agent.zip) · [返回七个助手的总介绍](https://github.com/hanxu66/hanxu-user-skills#readme)

下载 ZIP 并解压，将整个 `hanxu-script-agent` 文件夹交给你电脑上的 Codex，说：“请帮我安装这个 Skill，检查所需依赖并告诉我如何调用。”也可以手动把完整文件夹放进 `~/.agents/skills/`。不要只复制 SKILL.md，配套文件也需要保留。如果安装后未出现，重启 Codex。

## 开始使用

安装后，在 Codex 中输入以下示例，并附上自己的材料：

```text
$hanxu-script-agent
我想讲【题目】，给【目标观众】听。我的看法和材料是【内容】。
我有一些自己说过的话，附在后面。请学习我的表达，理清论点和论证、安排结构，写成完整口播稿。
```

没有历史语料也可以这样开始：

```text
$hanxu-script-agent
我没有历史语料。我想讲【题目】，给【谁】听，我现在的想法是【自己的话】。
请先用已有材料写；缺少影响内容成立的信息时再问我，通过对话和改稿逐步校准口吻。
```

返修时可以直接说：“这句话我不会这样讲，我会说【本人改法】。这次只改表达，保留论点、论证和结构。”想把偏好留给以后，可补一句“这是我的长期偏好”。

## 资料与接续

默认在当前项目的 `口播试用/` 保存本作者的表达记录及各题稿件；也可指定目录。以后写新题先回读同一作者记录，多作者分开目录。记录只在用户本地；跨聊天接续须能访问同一文件，无法访问时请带上表达记录。没有文件读写工具时，可在对话中复制记录接续。

本Skill将表达记录保存在你的本地目录，不执行对外上传或公开操作。作品发布与素材公开由你决定。

## 试用范围

这是帮助你逐步校准的试用版，首次生成不保证已像本人。个人适配看你的真实反馈，听者理解和平台效果需另行验证。纯文本样本不能证明已学习实际音色、语速和气口；本Skill不生成声音。

## 使用条件与范围

需要支持Skill和文件读写的AI环境，当前按Codex文件包交付；正文引用校验工具使用Python 3标准库。没有Python时可执行文字审读并说明检查范围，不假称程序已通过。语音材料需要环境本身能读取或你提供转写，安装包不含转写服务。

使用自己的材料和已获准使用的来源，模型与工具费用按实际服务计费。下载包需要在AI工具中运行。详细执行方法见 [SKILL.md](SKILL.md)。当前交付为用户试用版，许可范围沿仓库现行说明，不额外授予再分发或转售权限。
