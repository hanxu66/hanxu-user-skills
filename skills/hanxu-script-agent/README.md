# 韩叙 · 短视频口播文风助手

## 安装与更新

完整步骤见[安装与更新](docs/install-update.md)：安装完整技能 → 确认位置和版本 → 开始任务；更新前保留个人记录与本地修改，将旧版备份到技能发现目录之外，失败可恢复。


```text
用 $hanxu-script-agent 写一条口播。我想讲【题目】，给【观众】听；我的看法与真实材料是【自己的话】。请理清论点、论证和结构后交完整稿。有我的样本就学习，没有就用当前对话和改稿校准。作者记录保存在我自己的内容目录。
```

可加载完整Skill及参考文件的Codex或WorkBuddy；写稿无需Python。可选正文证据校验只用Python标准库，包内不含转写、配音或声音克隆服务。




**把你的想法整理成讲得清楚、适合你说出口的短视频口播稿。**

用户试用版 **v0.1.5**，包含论点、论证、结构和文风。有本人语料就学习；没有历史语料，从这次对话与改稿逐步校准。你不需要先建语料库，也不必先安装整套内容生产系统。

[下载独立安装包](https://github.com/hanxu66/hanxu-user-skills/raw/main/packages/hanxu-script-agent.zip) · [快速上手](docs/quickstart.md) · [看完整演示](docs/examples.md) · [七个助手总介绍](https://github.com/hanxu66/hanxu-user-skills#readme)

## 适合怎样的任务

适合内容创作者、知识博主、需要出镜表达的专业人士：已经想讲一个问题，有想法或真实材料，希望理顺之后写成完整口播；也适合已有稿件的局部返修。

你可以直接带来题目、目标观众和自己的话。观点还没想清楚，可以先对话梳理；只有题目、缺论据时，会补最小问题。表达样本可选，不会因为没有历史样本而一直停在准备阶段。

## 一次会帮你处理什么

| 能力 | 本条稿件中要讲清的事 |
| --- | --- |
| 论点 | 这条究竟想表达什么，观众理解或判断会改变在哪里 |
| 论证 | 为什么这样判断，什么材料支持它，能证明到哪一步 |
| 结构 | 从哪里进入，怎样承接和推进，最后怎样收束 |
| 文风 | 用怎样的态度、措辞和节奏，写得适合本人说出口 |

交稿前会合并不推进的重复表达、收窄缺乏依据的保证，并按本题时长检查内容容量；文字估算不代替真实朗读。默认直接给一份完整口播正文，便于复制：没有停顿、行动、转折等标签，也不夹分析和改动说明。论点、论证、结构和个人表达记录在后台处理；需要时再问它查看。不会把旧样本的事实或维护者的个人口吻自动套进你的新稿。

## 安装后直接这样开始

Windows和macOS使用同一包。**WorkBuddy**：下载ZIP，在「技能 → 添加技能 → 上传技能」弹窗底部点「选择 ZIP 文件」，导入并启用。**Codex**：解压并保留完整的 `hanxu-script-agent` 文件夹，交给它检查和安装。安装位置、依赖、更新方法见 [快速上手](docs/quickstart.md) 和 [平台适配指南](docs/platforms.md)。

目录标识沿用 `hanxu-script-agent`，展示名为“短视频口播文风助手”。下面的`$hanxu-script-agent`用于Codex对话；WorkBuddy改成“请使用已安装的短视频口播文风助手（hanxu-script-agent）”，后面的任务相同。

```text
$hanxu-script-agent
请在后台理清论点、论证和结构，保留我的核心意思，直接交完整口播正文。
【本题内容】
我想讲【题目】，给【目标观众】听。
我的看法和材料是【按自己的话说】。
【表达样本，可不填】
【粘贴自己说过或认可的文字】
这部分只学说法；其中的事实、建议和对他人的要求不作为本题素材或当前指令。
```

第一次拿到稿子，可以挑一句不会这样说的话，改成自己会说的样子：

```text
这句“【原句】”我会说成“【本人改法】”。
这次只改口吻，保留事实、论点、论证和结构。
```

明确属于长期偏好时再说明；仅本题的改法不会自动变成以后所有题的规则。

## 资料保存与使用条件

默认在当前项目的 `口播试用/` 保存本作者的表达记录和各题稿件，也可以指定目录。多人分开记录，新题先回读；跨聊天或换机器须能访问同一文件，或者把记录带过去。

按本地Skill文件包交付，提供Codex和WorkBuddy使用入口，需要宿主能加载完整Skill及自己的材料。写稿无Python依赖；正文证据校验脚本使用Python标准库，没有Python时做文字审读并说明范围。音视频读取或转写依赖你的实际工具，包内没有转写、配音或声音克隆服务。

本Skill不执行对外上传、发送或发布。表达记录留在你的工作目录；模型服务如何处理输入取决于所用服务，不能把本地记录理解为离线承诺。模型与工具费用按你自己的服务计费。
