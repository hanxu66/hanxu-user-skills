# 韩叙 · 短视频写稿助手

已经有选题和观点，想写成自然、能直接拍摄的口播稿。

## 适合谁

内容创作者、知识博主、需要出镜表达的专业人士。

## 你提供什么

已确认选题、你的观点和真实案例、目标观众。

## 你会得到什么

观点立意、内容结构、完整口播逐字稿。

## 下载与安装

[下载这个助手的安装包](../../packages/hanxu-script-agent.zip) · [返回七个助手的总介绍](../../README.md)

下载 ZIP 并解压，将整个 `hanxu-script-agent` 文件夹交给你电脑上的 Codex，说：“请帮我安装这个 Skill，检查所需依赖并告诉我如何调用。”也可以手动把完整文件夹放进 `~/.agents/skills/`。不要只复制 SKILL.md，配套文件也需要保留。如果安装后未出现，重启 Codex。

## 开始使用

安装后，在 Codex 中输入以下示例，并附上自己的材料：

```text
$hanxu-script-agent
根据我提供的选题、观点和真实案例，写一份可拍摄的口播逐字稿。
```

## 使用条件与范围

需要可用的 Codex，以及你自己的观点和材料。

你需要提供自己的素材、授权和品牌信息。模型和工具的实际费用按你使用的服务计费。当前是可下载的 Skill 文件包；不是一个点开网页就能直接运行的在线应用。详细执行方法见 [SKILL.md](SKILL.md)。
